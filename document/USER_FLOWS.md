# 用户流程与页面行为

版本：v0.2

状态：产品流程基线草案，页面原型和可用性验收待完成。对应产品需求见 [PRD](PRD.md)，本文件不代表页面或功能已经实现。

## 1 角色、入口与页面

学生与教师分别使用不同账号类型。学生无需登录即可创建本地学习空间；教师通过教师身份入口管理自己维护的课程内容、任务和反馈。教师也可独立进入个人学习空间。访客转账号只承接当前未绑定空间，不改变已有账号空间归属。

| 页面 | 主要内容与操作 | 关键状态 |
|---|---|---|
| P00 学习入口 | 选择课程、表达想学的目标、提交问题／作品；提供本地开始和登录入口 | 未选课程、信息不足、创建目标失败 |
| P01 课程图谱 | 全课节点与关系、课程／目标状态、搜索定位、核心／选修范围切换 | 蓝图加载、已定义范围、未发布、局部展开、当前目标 |
| P02 目标确认 | 显示目标草案、范围和达成条件，学生可编辑、确认或重选 | 草案、等待学生确认、已确认、已修改、暂存 |
| P03 学习工作区 | 同一活动中查看问题／理论／资料、操作作品、运行结果、询问 Agent、检查下一步 | 等待学生、处理中、等待工具、结果待解释、待核验、可继续、保存失败 |
| P04 作品与核验 | 提交版本、查看标准范围、运行或交核验、查看每项结果 | 排队、运行中、成功未核验、满足、未满足、工具失败、人工复核 |
| P05 证据详情 | 查看关联目标、作品版本、核验条件、帮助、来源、时间和变更原因 | 可追溯、存在冲突、缺依据、版本过期 |
| P06 课程与进度 | 查看课程范围、章节目标分布、下一步和需补内容 | 课程版本、范围不完整、范围切换、无可统计目标 |
| P07 资料与 Skill | 上传／整理资料、创建导入 Skill、私人试用、复核状态及分享范围 | 上传中、失败、私人草案、待校核、可试用、已发布、停用 |
| P08 账号与同步 | 登录、确认待承接空间、同步队列、冲突、导出、删除和账号切换 | 已关联待同步、部分同步、冲突、离线、本账号空间 |
| P09 教师工作区 | 课程内容、课程目标、任务发布、答案开放规则、学生授权内作品和反馈 | 草稿、审校、已发布、关系待接受、授权撤销 |

列表／树视图需提供与图谱相同的课程结构、状态、来源和入口。键盘焦点、状态文字、加载与错误信息不能只靠颜色、动画或悬浮提示表达。手机窄屏可以按层级浏览，不丢课程分母、关系方向和可用动作。

## 2 UF01：自主启动与目标确认

1. 学生从课程目录／图谱、问题／作品上传、方向描述或“不确定”入口开始；可跳过登录与参考资料。
2. 系统先查找所选课程已发布的当前版本蓝图，说明范围和未支持的特定环境。未发布课程不伪装完整支持。
3. 系统可基于学生自述或已有作品提出一个范围较小的目标草案，指出什么仍未知，并提出可操作的首项活动。
4. 学生查看目标、范围、必要表现和下一步，可以修改、确认、暂存或返回课程图谱。未确认的草案不算既定学习承诺。
5. 已有基础的学生可以选择直接核验某目标；未知表现保持未知，不强迫完整重学，也不把自评问卷直接变成通过证据。
6. 无登录时目标和作品保存于当前本地空间，界面显示本地保存状态；存储失败须停止承诺“已保存”，提供重试或导出。

## 3 UF02：课程图谱与目标证据

1. 首屏显示正在看的课程、蓝图版本、核心／选修和个人计划范围，按课程→章节→知识单元→目标分层呈现。
2. 每个父节点展示去重目标数量和各状态分布；目标在多个章节引用只计一次。过滤和折叠清楚标出可见子集，却不改变全课分母。
3. 关系菜单解释归属、先修、概念／应用的名称、方向和来源。关系指导路线，不推断任何学生目标已达标。
4. 目标详情显示必要条件、实际作品版本、核验与帮助、来源和时间、冲突／环境限制、下一个可做动作。
5. 学生可从目标进入理论回顾、活动实践、已有基础核验或选择其他目标。入口保持当前目标和课程版本。
6. 有效核验或课程标准变更完成后刷新实际受影响的目标与父节点，并说明变化来源；保留当前选择、展开层级和位置。点击／拖动不触发状态写入。
7. 蓝图不完整、统计分母为零、部分核验能力暂缺时显示相应说明，不能用 0% 或 100% 隐藏限制。

## 4 UF03：理论与实践往返的工作区

工作区让学生连续理解、尝试、观察和修正。概念不足者可以先看必要说明／示例；已有基础者可先动手或预测结果。系统不得用看完整章或先猜未知概念来解锁实践。

1. 顶部维持目标、完成条件和当前活动版本；中心聚焦问题与学生正在构造的产物。
2. 理论解释、任务要求、资料出处和示范按需查看，返回时保留作品及运行状态。
3. 学生可以进行非测评试验、保存版本、运行和解释现象。Agent 引用实际作品／结果给建议，随后给学生明确的下一项动作并等待。
4. 帮助层级在使用前说明；记录学生看到的提示／示例／答案和实际披露版本。答案政策按自学或教师发布来源执行。
5. 有意义的阶段才进入核验。核验任务显式说明将检查的条件；学生可退出、继续修改或选择暂缓，不把点击次数当成测评。
6. 任何保存、工具或 Agent 失败都可恢复到最近持久化版本，标明未保存／未完成部分；环境故障不转换成学生错误。

## 5 UF04：执行与实作

- **代码**：选择实际启用的语言／版本，编辑源码、提供输入、运行，查看真实编译器／解释器输出，修改版本并重试。运行成功和正确性核验分别显示。自动评测绑定运行源码、依赖／镜像、输入、测试集和标准版本。
- **SQL**：显示独立数据库、所用数据版本和重置操作；真实查询返回结果集和约束检查，不能连接业务库。
- **网络**：启动授权模板，连接受控终端，执行并观察网络状态、报文／抓包及自动检查，保存拓扑配置和采集边界；环境无法恢复时说明需重建和复查。
- **推演、证明与设计**：保留步骤、图表、反例和版本；按活动中的依据核验，无法自动确认时进入待人工复核。
- **数据／机器学习实验**：保留数据来源、划分、处理步骤、依赖、随机配置、代码和指标；运行结果本身不能覆盖推理解释要求。

学生退出或切换活动前，如果有尚未持久化的改动，明确给出保存进度；客户端不得伪报正在运行任务的最终结果。

## 6 UF05：核验、状态更新和再学习

1. 核验服务先校验作品版本、目标映射、任务、标准、来源、所有权和运行状态。
2. 通过某项条件只记入此作品／标准版本所覆盖的目标维度。执行异常、检查器失败、超时和证据缺失用工具状态表示。
3. 核验结论显示满足／不满足的具体条件、解释或人工复核意见、帮助范围和下一步；争议保持待核验。
4. 更新通过业务证据校验后，按该课程的状态规则重算相关目标／节点聚合；迟到结果写入原尝试，修改后的旧作品结论不覆盖新版本。
5. 必要条件均满足时可显示“当前标准下有达标证据”。部分满足／帮助后完成、有效证据显示不足、尚未评估分别呈现。
6. 图谱只更新被证据覆盖的目标。学生可以补理论、改作品、进入新条件活动、继续相邻目标或之后接受再检验。
7. 后续观察只记录真实新证据；系统不得仅因经过时间将过去目标标为遗忘。

## 7 UF06：访客、本地空间与账号同步

1. 未登录开始先创建匿名本地空间标识；作品、目标、尝试、帮助、证据、待执行动作和恢复位置均归入该空间。
2. 访客使用在线执行或模型时，开始前显示该服务将临时处理的数据类别和可用条件；平台不创建永久云端访客学习档案。
3. 登录后只自动承接当前明确尚未绑定的空间，显示来源、账号、对象计数和关联／待同步进度。已登录账号空间内的数据不出现在导入预览中。
4. 上传采用稳定对象标识、版本和幂等操作；逐对象报告成功、待同步、部分失败和冲突。附件确认云端可取后才标记完成。
5. 账号切换立即切换存储命名空间并停止旧身份任务。A 的缓存或迟到结果不能转给 B；要继续 A 的同步，须重新验证 A。
6. 并发修改保留双方版本并提供选择／恢复；删除标记及撤销授权会传播，旧端同步不复活内容。
7. 新设备登录只下载该账号已授权数据；未授权教师、其他账号或未知所有者内容不可导出／检索。

## 8 UF07：教师支持与发布任务

1. 教师账号进入独立教学空间，建立或维护课程范围、资料、知识结构、活动和核验标准的版本；内容未经审核时标记草案。
2. 发布任务时固定来源、所属课程和目标、任务／参考答案版本、答案开放规则、提示范围和生效条件。发布前教师检查学生可见说明。
3. 学生打开教师任务时看到其来源、开放条件和适用规则。查看答案请求由服务端按发布实例／策略校验；学生自学任务仍按学生自己的策略。
4. 学生关联教师并单独授权课程和查看范围后，教师只看该范围的目标、作品、核验及学生允许的帮助摘要。学生可撤销授权；撤销后停止新读取和分发。
5. 教师反馈绑定当前作品和任务版本；修改发布内容保留旧版本、历史帮助和旧核验条件，不能覆盖过去证据。
6. 学生或教师报告课程内容或判断错误，进入可追溯复核；可发布修订版并指出受影响范围。

## 9 UF08：资料与 Skill

资料上传显示所属空间、出处、解析状态和版本。教师／学生均能创建或导入私人 Skill，看到结构与权限检查结果后在允许范围内试用。设计角色按需生成草案；作者不能凭结构正确就发布可信教学标准。独立核验、审核和分享各有状态。分享前预览仅会公开的定义／附件，确认发布范围；采用者可固定版本、停用并恢复，不连带分享聊天、作品和私人附件。

## 10 页面级交付与验收

页面规格应先完成流程原型，再提供原创视觉方向、关键页面高保真设计、完整组件与状态规格、可见文案、交互控件、键盘操作、加载／错误／空数据状态、角色与授权矩阵，以及对应 FR 编号。覆盖 P00–P09 和 UF01–UF08 的正向与拒绝路径。

实现页面须遵守 [前端设计与品质标准](FRONTEND_DESIGN_STANDARD.md)，以 Awwwards、Webby Awards、FWA 获奖级网站为品质标准，分别完成八维自检、修正和独立复核，持续优化到没有明显可提升之处。视觉设计要保持理论、作品、真实结果与辅导的连续工作区，以及课程图谱的真实状态和可追溯入口；窄屏应按任务重组布局。

最终测试通过证据保留于 [综合测试计划](TEST_PLAN.md) 的追踪矩阵及测试报告。截图和录像用于说明可复现的检查结果，不能单独代替功能与品质测试通过。
