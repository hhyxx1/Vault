# 连续代码学习的临时会话续接

2026-10-10。全13课页面走查暴露：每次完整刷新使客户端内存租约丢失，默认30分钟空闲有效的旧租约仍占容量；第九课M10开始返回GUEST_CAPACITY_REACHED。不能把该失败记作知识错误，也不能扩大容量掩盖。

修复复用同tab的匿名临时能力，存于该origin的sessionStorage；不存账号session、执行服务密钥或学习作品，不进入导出/同步。账号认证仍使用既有HttpOnly cookie。storage不可用时回退内存。缓存到期按空闲/绝对两个日期较早者判断，服务端仍是权限和期限权威。

代码提交只在服务端明确返回GUEST_LEASE_EXPIRED或GUEST_BUDGET_EXCEEDED、且尚未接受本次operation时，清理该缓存并新租约重试一次。保留原冻结作品和幂等标识。繁忙、Origin拒绝、网络未知结果、已接受作业或内容绑定不一致不自动重跑。其他核验/助手API失效时也清理缓存，但本轮没有给模型预算失败增加自动续接。

单元测试从RED到GREEN验证刷新复用、到期续接、配额续接、繁忙不续接；前端完整92通过，类型和契约检查通过。全目标桌面走查重跑中，不预写366目标全部通过。每课测试检查20次配额下最多两次授权，不降低服务端20操作/租约、256并存租约及单作业限制。

原失败走查前八课完整作者路径通过，第九至十一课容量失败，后续终止测试运行以修复；服务保持可用，后端替换后重新走查。参考答案走查只验证固定条件和恢复，不认证独立掌握或Q0–Q5完整课程。
