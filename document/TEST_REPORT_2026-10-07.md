# 本轮严格测试记录（2026-10-07）

## 范围

本轮针对课程知识图谱/学习地图切片进行验证。该实现以现有 CS03 栈课程包作为样例，不代表 13 门课程已建设完成，也不代表第一阶段产品验收完成。

## 本轮实现覆盖

- 学习地图从课程包中的稳定目标 ID 和关系生成，不再在 UI 中硬编码节点总数或假设每个目标只有两项。
- 目标掌握状态按目标 ID 记录；重复目标去重，折叠节点和关系筛选不改变课程目标总数。
- 包含关系用于图布局；父节点汇总只展示子目标状态，不把掌握状态向父子目标传播。
- 支持关系筛选、节点折叠、缩放、适配视图，并提供键盘可访问的文本摘要。
- 桌面宽屏与窄屏采用不同布局；移动端控件换行，避免页面横向溢出。
