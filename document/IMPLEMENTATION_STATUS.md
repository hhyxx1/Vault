## 本次可信闭环

从入口进入栈样例 → 确认目标 → 自主预测七步操作 → 需要时查看原理／参考答案 → 保存不可变作品版本与求助快照 → 提交临时服务 → 后端执行固定操作并逐行比较 → 校验返回 hash／版本与来源 → 本地事务写入核验 → 确认服务清理 → 在作品、证据与图谱中继续学习。

正确的固定推演仅满足部分标准。解释和独立迁移仍待复核，因此图谱不会自动将目标标为“已掌握”。核验期间继续编辑会形成新草稿，旧结果只对应提交版本；重新核验才能评价新的作品。提示／答案使用保留在对应提交快照，不能在后续查看后改写旧记录。

## 账号与同步的实际边界

本机可注册、确认邮箱、登录、退出和恢复原账号记录，邮箱暂由私有开发捕获器提供，生产明确关闭。登录后先固定未绑定本地空间的本人归属，服务器确认 claim 后逐项同步；响应丢失、切换账号或刷新不会把 pending 记录转给他人。空访客空间登录时恢复本人原空间，有新增学习时另行承接并分别保留。

同步保存作品、版本、求助、核验历史、私人备课草稿和继续位置，跨设备恢复的核验来源明确为 client_reported／待复核；本机已有同正文真实核验可保持原来源，云端字段不能自授可信度。版本冲突保留本机与服务器双方，并提供选择；删除底层协议使用 tombstone，页面完整删除流程尚待实施。
