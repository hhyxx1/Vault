## 本次可信闭环

从入口进入栈样例 → 确认目标 → 自主预测七步操作 → 需要时查看原理／参考答案或按次请求 Agent 辅导 → 保存不可变作品版本与求助快照 → 提交临时服务 → 后端固定检查器逐行比较 → 校验返回 hash／版本与来源 → 本地事务写入核验和帮助事件 → 可选地在服务端结果清理前请 Agent 解释本次核验 → 确认服务清理 → 刷新后从本地记录恢复答复、作品与图谱状态；从答复一键回到可编辑作品，继续修改并重新核验。

正确的固定推演仅满足部分标准。解释和独立迁移仍待复核，因此图谱不会自动将目标标为“已掌握”。核验期间继续编辑会形成新草稿，旧结果只对应提交版本；重新核验才能评价新的作品。提示／答案使用保留在对应提交快照，不能在后续查看后改写旧记录。

## 账号与同步的实际边界

本机可注册、确认邮箱、登录、退出和恢复原账号记录，邮箱暂由私有开发捕获器提供，生产明确关闭。登录后先固定未绑定本地空间的本人归属，服务器确认 claim 后逐项同步；响应丢失、切换账号或刷新不会把 pending 记录转给他人。空访客空间登录时恢复本人原空间，有新增学习时另行承接并分别保留。

同步保存作品、版本、求助、核验历史、私人备课草稿、个人课程及不可改写的自述尝试和继续位置，跨设备恢复的核验来源明确为 client_reported／待复核；本机已有同正文真实核验可保持原来源，云端字段不能自授可信度。个人课程与尝试同步不产生平台核验结论，也不变成教师发布课程。版本冲突保留本机与服务器双方；个人课程双设备同时追加学习点时尚无无损合并界面，应先导出本机记录再人工处理，不能直接采用云端覆盖新增学习点。删除底层协议使用 tombstone，个人课程删除及页面完整删除流程尚待实施。

实现及契约见 [账号同步切片](ACCOUNT_SYNC_IMPLEMENTATION.md)，实际验证见 [技术验证](TECHNICAL_VALIDATION.md)；教师关系、资料、附件、完整的学生个人课程教学能力、Agent、执行与完整默认课程没有因账号同步切片而自动完成。
