## 本次可信闭环

从入口进入栈样例 → 确认目标 → 自主预测七步操作 → 需要时查看原理／参考答案 → 保存不可变作品版本与求助快照 → 提交临时服务 → 后端执行固定操作并逐行比较 → 校验返回 hash／版本与来源 → 本地事务写入核验 → 确认服务清理 → 在作品、证据与图谱中继续学习。

正确的固定推演仅满足部分标准。解释和独立迁移仍待复核，因此图谱不会自动将目标标为“已掌握”。核验期间继续编辑会形成新草稿，旧结果只对应提交版本；重新核验才能评价新的作品。提示／答案使用保留在对应提交快照，不能在后续查看后改写旧记录。

## 接下来按顺序实施

1. 建立两类账号的真实会话与受限授权、claim journal、幂等领取和账号切换隔离；补齐响应丢失、离线、附件与冲突恢复测试。
2. 接入 LangGraph／模型网关与四项学习职责；把规划、解释、实践、核验纳入当前作品和标准约束，完善 Skill 版本与校核。
3. 接入专用 Linux 隔离执行环境，以真实编译结果和资源回收测试支撑代码证据；随后扩展 SQL、网络和其他课程活动。
4. 教师自建课程／资料可见副本／RAG／发布撤回；与课程包工作流合并。
5. 13 门课内容持续并行编制和教研审校，逐课验收；最后完成全 P0、前端、容量、恢复和发布门。

每次按完整切片提交测试和状态记录，不能仅以某库安装或一个活动通过宣称整模块完成。当前不具备公开付费服务能力，也没有真实学习效果或运营数据。
