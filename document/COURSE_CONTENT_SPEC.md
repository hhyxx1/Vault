# 课程内容与核验包规范

版本：v0.2

状态：首版内容契约草案。第一阶段必须交付 CS01–CS13 全范围版本化内容；本文件规定可检查结构，尚未证明任何课程蓝图、标准或执行环境通过审校。

## 1 全课程完成定义

CS01–CS13 每门平台默认课程须包含有来源可追溯的范围和深度、章节／主题、全部知识单元及稳定目标、目标关系、必要理论材料、学习活动、适用工具、核验标准、失败与未知处理、恢复条件、帮助与下一步。全范围通过编审清单确认无“未编写但假装不适用”的节点。

目标支持类型逐项标记自动工具核验、结构化推演、人工复核或明确不能核验；没有自动核验的证明、开放设计和专用物理实验仍纳入课程结构，并通过适合的教学／提交／人工审阅方式处理。功能边界须向学生明示。课程目录只有在其全部约定的目标和活动均审阅通过后才显示“第一阶段完整支持”。

## 3 必填内容字段

| 对象 | 必填字段 | 检查规则 |
|---|---|---|
| 课程版本 | 稳定 ID、标题、蓝图版本、声明范围／深度、核心／选修、先修、资料引用、作者与审校、状态 | 已发布版本不可变；来源和版本有效；范围排除公开说明 |
| 章节／单元 | 稳定 ID、父节点、标题、顺序、属于核心或选修、内容目标映射 | 层级无循环；父层不能代替可检验目标；目标可多处引用但不重复统计 |
| 学习目标 | 稳定 ID、可观察表现、必要条件／维度、先修关系、目标版本及映射、有效证据种类 | 不得只用“理解／掌握”；须指出学生能展示什么以及适用边界 |
| 理论依据 | 概念／定义、说明、例证或反例、出处／章节／页码／链接、内容审校状态 | 学生可追溯来源；资料不可用和冲突有处理记录 |
| 活动 | 要解决的问题、目标、前置理论（必要时）、学生必须动手的操作、产物、允许试验、预期现象、反馈分支、帮助级别、恢复条件 | 理论与学生动作相连；Agent 不代交必要表现；普通探索不强制核验 |
| 核验标准 | 对应目标及作品类型、必要条件、可接受替代解、正确／错误／证据不足例、评分或人工审阅步骤、检查器和版本 | 内容、题、预期答案和测试不能由同一次生成互证；有人工审阅人及日期 |
| 工具契约 | 必要能力、允许运行环境／版本范围、输入输出、资源和网络限制、故障状态、真实结果证据 | 工具不可用时维持未知／未核验；不编造输出 |
| 救助与再学习 | 常见错误／误解、按来源允许的分层提示、示范内容、修改动作、新条件任务、后续检查 | 答案规则可覆盖；提示披露可记帮助；迁移任务不是答案复制 |
| 发布元数据 | 来源类型、所有者、审阅人／角色、标准版本、范围覆盖、限制、发布范围、许可、平台验收状态 | 未审内容只可草案或私人试用；教师范围发布不等于官方收录，发布有责任人和撤回路径 |
| 资料绑定与派生内容 | 资料／学生副本版本、课程绑定、学生可见设置、来源定位、授权版本、生成与审阅记录 | 默认私有；学生内容明确发布，原件／切片不自动公开，备注与隐藏页排除规则和下载一致 |

## 4 关系与统计

课程结构是有向无环的组织树，跨章节目标引用用稳定映射实现。学习关系分类型维护：包含／归属、严格先修、概念关联、后续应用和证据支持。关系必须记录来源、方向、课程版本和维护理由；关键词相关不自动生成先修边。

每个统计目标有一个稳定可判定 ID。核心、扩展和个人计划是不同范围集合，范围过滤不变更全课分母；无法核验的目标注明支持能力及原因。父节点从所属集合去重计算，证据节点和活动节点不参加目标分母。

## 5 内容状态与审校

平台默认内容沿用 `draft` → `structured_validated` → `content_reviewed` → `course_accepted` → `published` → `superseded`。

教师自建课程使用 `draft` → `structured_validated` → `teacher_reviewed` → `scope_published` → `superseded`；发布前明确完整声明范围和活动限制，通过结构／权限检查及教师内容审阅。待适配目标保留在图谱和分母中但不开放为可执行／可核验活动，已开放活动须有实际实践、提交及核验／复核路径。平台官方验收／收录另行记录，不能从 `scope_published` 自动推定。

四类核对人／工具职责应尽量独立：课程范围审阅、概念与解法审阅、执行环境与测试审阅、课程包发布责任。开放性论证无法自动判定的部分由人工复核，不强行把所有客观内容伪装成自动评分。

## 6 发布门槛

课程需通过范围覆盖、引用、目标唯一性与关系校验，理论—活动—目标映射检查，适用核验集的正确／错误／替代答案检查，运行与故障案例，答案／数据权限测试，版本迁移／恢复检查以及课程支持报告。CS01–CS13 逐门记录，不汇总成一个跨课程通过率代替明细。

机器可读源文件、版本化发布包、审校记录和测试结果按实现后确定的目录／仓库存放；项目设计说明统一放在 `document/`。私有学生作品、教师私人资料和密钥不进入共享课程包或 Git。

## 7 教师自建课程与资料建立

教师可从空白、授权模板或大纲／PPT／资料生成独立课程包，不限默认 13 门。沿用目标、关系、理论、活动、核验、帮助与恢复结构；复制不带学生证据、无权资源或更宽的发布授权。大纲／资料更新生成草案差异，教师审阅后发布新版本，保留历史证据及目标兼容映射。

教师私有材料可供备课 AI 使用，但生成图谱、理论、任务和 Skill 仍是私有草案。教师预览并明确选定独立学生发布物后，仅发布物在其范围内可用；其来源记录保留于有权的教师视图，不能向学生暴露私有原件、源切片或私有引用。学生问答 RAG 另按资源学生可见性、课程访问及受控来源的原发布实例答案策略求交集，不因无任务问答或换任务取消关联，见 [资料解析与 RAG 权限设计](RAG_AND_RESOURCE_DESIGN.md)。

PPT／PPTX、PDF、DOCX、TXT／Markdown 至少纳入导入测试；PPT 备注、隐藏页与嵌入附件默认排除学生提供，显式纳入前预览。需排除内容时生成学生副本并使下载、解析、切片一致；不能仅删除索引而开放含私有内容的原件。解析遗漏、扫描件／公式图表和工具缺口须登记，教师课程的范围发布不能冒充平台已验证该课程全部内容与实验。
