# 学习助手实现切片

版本：v0.1。日期：2026 年 10 月 6 日。状态：开发切片，尚未启用真实模型。

## 范围

本切片只面向待教研审校的 CS03 栈工程样例目标 `CS03-STACK-01`，用于打通学生主动请求、Agent 分工、结果解释、记录恢复和账号同步。它不代表 CS03 完整课程，也不代表 13 门课程已获得 Agent 支持。

学生可以按次请求诊断、原理解释、提示或新情境练习。学生还可以单独选择在确定性核验完成后请求 AI 解读；该请求必须引用同一租约中仍可访问的服务端核验操作，并匹配课程／活动版本、目标、作品 ID 和修订 ID。服务端只向解读职责提供核验摘要、逐项标准状态和固定来源，不接受客户端伪造核验摘要。

## 数据和权限边界

- Agent 工作流由 LangGraph 路由到诊断、辅导、练习设计或核验解释职责；每次最多一次模型调用，无工具、无 shell、无数据库写入、无发布能力，也不启动学生代码。
- DeepSeek Responses API 由服务端 httpx 网关调用，使用结构化 JSON 输出和有界时间／并发。Responses API 无状态；本项目每次只传本请求所需的目标、问题、选定作品摘录、解释和必要核验摘要，不发送账号 ID。
- 发送前界面分别要求学生同意普通辅导内容或核验结果解读；未同意时不发请求。DeepSeek 会收到被选中的内容；不能把 API 文档描述解释为供应商零日志或零保留保证。公开开放前仍需审查实际数据处理和隐私条款。
- Agent 输出的 `mastery_asserted` 固定为 `false`。它不能写入 Objective 状态、证据可信度、教师权限或答案开放规则。图谱状态仍只由现有确定性核验／审阅规则更新。
- 成功交互存为 `agent_assist` 帮助事件，记录提问、答复、下一步、课程／活动版本、作品／修订 ID 与披露版本。访客记录在浏览器 IndexedDB；账号记录沿用既有帮助事件同步契约。同步导入的 Agent 文字是客户端报告，不能因此成为可信学习证据。
- 每个临时租约最多 6 次助手请求；相同请求标识和内容返回缓存结果，标识冲突会拒绝。临时服务内存记录随租约清理。应用默认 `VAULT_AGENT_ENABLED=false`，启用时需要后端 `VAULT_DEEPSEEK_API_KEY`；示例环境文件不含有效密钥。

## 当前限制

真实 DeepSeek 请求没有在这轮开发中运行或验证，仓库／本机未配置有效 API Key。CI 与本地假传输覆盖请求格式、结构化响应解析和失败边界。当前本机离线缓存没有 LangGraph 所需的 `langsmith` 轮子，因此完整图路由用例在本地跳过；CI 安装锁文件依赖时会执行该用例。

本切片没有 PG LangGraph checkpoint、跨进程／重启恢复、多轮会话历史、教师 Agent、自建课程资料 RAG、用户自定义或上传 Skill，也没有对其他 12 门课接入。调用次数预算当前以临时租约为界，不代表长期账号配额或生产容量策略。模型答复可能有错误，仍应配合学生的独立尝试与固定核验。

DeepSeek 请求契约参考：[Responses API](https://api-docs.deepseek.com/api/create-response/)；技术选型、数据与工具边界见 [技术基线](TECHNOLOGY_BASELINE.md)。
