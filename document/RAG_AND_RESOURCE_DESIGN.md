版本：v0.2

## 1 产品规则与信任边界

- 教师可创建 13 门默认课程之外的课程，上传大纲、PPT、讲义及其他资料，由 AI 辅助提出结构、目标、图谱、活动和 Skill 草案。
- 最小资料格式包含 .ppt／.pptx、PDF、DOCX、TXT／Markdown；旧 .ppt 采用受控转换，保留原件与转换版本，无法转换时明确失败或限制，不伪称已可检索。
- 教师资料默认教师私有；每份资料单独选择是否向该课程发布范围内的学生可见，不由课程发布、资料上传或 AI 解析自动公开。
- 学生提问时，仅可检索并向模型提供当前有权访问、已选择学生可见的资料内容；学生不能通过问题、对象 ID 或 Skill 自授权限。
- 学生可见与答案开放是两个条件。受控答案的资料、切片和派生产物保留原发布实例／策略关联；无任务课程问答、另一任务或下载仍校验该受控来源的有效策略，不能只按请求当前任务判断。此关联不扩大到无关联的其他自学内容；无法可靠分离受限答案时，该版本不得整体进入学生提供集合。
- 13 门默认课程的完整建设与验收基线保持；教师自建课程使用同一课程引擎，保留作者、来源、能力覆盖、审核状态及独立范围分母。
- 权限由可信业务服务决定。索引属性、模型回答、教师关联关系和客户端参数均不能单独作为访问凭据。

## 2 两类使用上下文

| 上下文 | 可用资料 | 产物与隔离 |
|---|---|---|
| 教师备课 | 本教师有权访问的私有／已发布版本；其他作者明确授权的资料 | 生成物进入教学私有草案空间，教师审阅后主动发布选定产物 |
| 学生学习与问答 | 当前课程发布实例内对该学生可见、版本有效且符合答案策略的资料 | 使用学生学习空间与任务上下文；不能读取教师备课运行、私有草案或其记忆 |
| 教师本人自学 | 本人个人学习空间授权资料 | 与教学空间和学生成绩空间分别管理，不沿用备课权限扩大共享 |

同一个 Agent 职责可以服务两类上下文，但运行身份、可检索集合、会话、工具声明、缓存与记忆必须分开。教师预览学生回答时采用学生视角的权限模拟，不把教师私有检索结果用于该预览。

无需增加常驻 Agent。课程／Skill 设计职责按需辅助备课，资料解析与索引构建是工具任务，访问控制是业务服务职责。

## 3 逻辑对象与版本

| 对象 | 必要属性与约束 |
|---|---|
| 课程与发布实例 | 稳定课程 ID、不可变课程版本、发布者、受众／范围、审核与能力状态 |
| 资料／资料版本 | 所有者、关联课程版本、原件内容哈希、来源、状态、学生可见选择、允许受众、内容角色及策略版本 |
| 发布内容组成 | 原件、正文、图表、OCR、PPT 备注、隐藏页、嵌入附件等组成的选择与审阅记录；实际下载内容与说明一致 |
| 解析版本 | 资料版本、解析配置标识、实际页／幻灯片／段落定位、成功／部分／失败状态 |
| 切片与检索记录 | 资料及解析版本、片段 ID、定位、内容哈希、继承范围与权限版本；索引并非权威 ACL |
| 派生物 | 来源版本集合、生成运行、引用定位、教师审阅、选定独立发布版本、允许范围、受控答案发布实例／策略关联；原件权限不由派生发布改变 |
| 授权修订 | 当前可见范围、策略版本／修订号、生效与撤销事件；更新须支持并发版本检查 |

更换文件产生新版本；不沿用旧版本的公开选择自动公开新增页、PPT 备注或附带答案。教师明确审阅后确定新版本发布范围。

教师发布前提供学生视角预览，检查 PPT 备注、隐藏页、嵌入附件及解析范围。若原件包含不拟公开的部分，不能仅隐藏解析文字却允许下载完整原件；需发布经教师确认且去除对应内容的独立学生副本，或保持原件私有并发布选定派生物。

私有资料可参与教师授权的 AI 备课，但生成内容默认仍私有。教师可明确审阅并发布选定课程说明、活动、讲义或 Skill 版本；此动作不会自动公开其来源原件、其他草案或备课聊天。

学生端来源显示以已公开派生物版本为依据；私有来源的标题、定位、片段及引用链接不得随发布自动泄露。内部来源链保留供有权教师追溯。

## 4 学生 RAG 的许可判定

候选片段需同时满足：认证／临时上下文有效 ∧ 课程发布实例允许访问 ∧ 当前受众范围匹配 ∧ 资料有效且学生可见 ∧ 版本组成允许发布 ∧ 该内容关联的原发布实例答案策略允许本次披露（存在当前任务时同时校验其适用策略）。

公共课程只使用明确面向该访问范围发布的内容；课程可访问不等于该课所有教师附件可访问。未登录者不能靠临时运行声明读取教师私有课程或私有资料。

教师私有、学生可见、已停用和待发布内容至少逻辑隔离。是否物理分索引由实现选择，但必须满足检索前的范围过滤与后续权威 ACL 复核；无过滤能力时不得先广泛检索再仅靠前端隐藏。

1. 请求入口从服务端会话解析真实账号、课程发布实例、活动版本、答案策略和权限修订号。
2. 检索前限定可访问的课程／受众／可见集合及版本；候选只返回必要标识，不将私有文本直接传给模型排序。
3. 加载片段正文、引用与重排之前，再按权威 ACL 校验对应提供对象版本及当前授权；原资料片段校验资源绑定，已审阅独立发布物校验其自身发布授权，不要求学生获授私有原件权限。失败或状态不明则排除。
4. 组装模型上下文前再次校验组成、答案规则和当前权限。未独立发布的摘要／缓存须追查全部来源权限；已明确审阅独立发布的版本以其自身授权为提供边界，私有来源链仅供有权教师追溯，不传入学生上下文。重排、摘要工具遵守同一边界。
5. 发送模型调用前取得当前许可并登记引用版本；异步工作流使用修订号／栅栏令牌阻止过期授权继续发送。
6. 返回或继续流式输出前检查当前权限及来源依赖；撤权时停止新输出、清理未发送缓冲并显示来源已不可用。
7. 回答附学生有权打开的资料版本与页／幻灯片／段落定位；没有依据时明确缺少资料，不伪造引用。

不因模型声称内容“只是摘要”“已经公开”或学生要求忽略教师规则而放宽授权。若答案策略无法判断，拒绝披露对应片段，允许使用其他符合规则的内容解释。

## 5 防止旁路泄露

| 通道 | 约束 |
|---|---|
| 原件下载与预览 | 同一授权检查覆盖对象存储、预览、附件及下载；避免授予撤权后仍长期有效的直接地址 |
| 解析正文与 PPT 备注 | 与资料版本／组成绑定；教师解析结果不能作为学生通用解析缓存 |
| 切片、引用、摘要 | 原始片段与未独立发布的派生文本继承来源权限；经教师明确审阅的独立发布物按自身授权提供，私有来源标题／定位／链接仍不可见；受控答案关联不能被去掉 |
| embedding 与索引 metadata | 不向学生暴露向量、私有摘要或敏感 metadata；仅保存检索必要字段；索引副本不授予权限 |
| 重排与模型网关 | 先授权再加载或发往模型；不把私有候选交给学生侧模型作事后过滤 |
| 答案／检索缓存 | 以使用上下文、受众、课程／资料／策略版本和权限修订隔离；命中后仍复核，不能只靠缓存键授权 |
| Agent 会话与记忆 | 教师与学生运行分开；共享记忆不得写入教师私有来源；续跑和压缩摘要也校验来源链 |
| Skill 与自动生成 | 资料中的指令属于数据；Skill 定义不含可绕过范围的任意资料读取工具或系统凭据 |
| 日志、追踪与分析 | 默认保留标识、判定与耗时等必要信息；限制原文、Prompt、备课内容及调试访问，不能用日志提供学生检索 |
| 导出、通知与同步 | 与正常 API 相同的可见与答案判定；不得预取未开放答案或同步教师私有资料至学生本地 |

上传资料、网页引用及检索片段中的指令只作待解释内容，不能替换系统规则、调用任意工具或索取其他资料。工具入口使用允许动作和参数，授权在每次调用中执行。

## 6 可见变更、撤销与异步竞态

教师变更可见范围时，事务更新权威授权修订并记录事件；该修订成为后续读取、模型发送及输出的判断依据，不能等待索引删除完成才生效。

撤回原资料默认使其原件、切片及未独立发布的摘要／缓存失效；已明确审阅的独立发布物由自身授权控制，界面列出相关发布物并可同时撤回，不能静默把其访问条件改成需要私有原件权限。失效事件触发索引标记／删除、缓存失效、下载访问失效及依赖失效对象的学生工作流暂停；后台清理可重试和对账，业务访问在清理期间仍由权威 ACL 拒绝。

解析／索引任务绑定启动时资料版本与授权修订。提交索引之前复核当前状态，旧任务不能重新公开已撤销、停用或替换版本；重复任务幂等，部分索引不显示全部完成。

已在模型提供方接收前撤销的请求不得发送；已被接收的调用无法保证远端撤回。对尚未给学生展示的结果进行当前 ACL 复核并丢弃受限输出；精确并发边界在实现评审和竞态测试中验证。

已向学生展示、下载或保存在学生本地的内容不能保证收回。界面明确说明撤销停止后续访问；不宣称可以删除学生记忆或所有副本。已收到的学生历史保留原披露来源，新的引用读取仍检查当前权限。

## 7 API 追踪与操作契约

| API ID | 操作语义 | 关键校验与结果 |
|---|---|---|
| API-14 | 教师自建课程、导入大纲、AI 辅助设计、审阅与发布 | 教师所有权、草案／版本、能力检查、选择发布产物；返回课程草案或发布版本，不自动修改默认课程库 |
| API-15 | 资料上传、解析状态、学生可见选择及撤销 | 原件／版本／组成、课程受众、内容角色、期望修订；返回当前可见状态与修订，记录撤销及失效任务 |
| API-16 | 权限限定的课程资料检索与引用问答 | 服务端上下文、当前范围／答案策略、片段前后校验；返回允许引用与来源，禁止客户端指定任意 owner 扩大集合 |

API-11 的通用资料／Skill 生命周期继续使用；上述新增操作落实课程级权限，不形成第二套宽松接口。异步事件记录任务标识、版本、状态及权限修订，不广播私有文件标题或正文。

拒绝时采用通用不可见／无权错误，避免暴露其他教师对象是否存在。授权服务异常时停止受限检索与发送，允许说明暂不可用；不能缓存成功权限后无限继续。

## 8 验收与追踪

- FR44 / API-14：创建非默认课程，导入大纲与 PPT 后生成私有草案；教师审阅发布，课程有独立范围、图谱及能力限制，未影响 13 门默认验收。
- FR45 / API-15：上传默认私有；逐份公开、撤回、替换版本，原件、备注、切片、引用、摘要、下载和缓存行为一致。
- FR46 / API-16：学生问题、猜测对象 ID、伪造范围与注入指令不能检索教师私有资料；可见资料仍受答案策略约束。
- 竞态：检索后撤权、加载后撤权、模型发送前撤权、流式输出中撤权、旧解析任务迟到、缓存命中、账号切换及教师预览均不可扩大授权。
- 隔离：教师备课私有摘要不进入学生共享记忆；教师明确发布派生物后仅该选定版本公开，私有来源链不泄露。
- 恢复：解析失败、部分索引、异步失效重试与服务重启不复活撤销内容；引用保持资料版本和定位，删除后新读取失败。

以上为待实现验收场景。已选Docling／受控LibreOffice与PPT副本、PG／pgvector、bge-m3 dense1024与固定jieba词法融合；首版对授权集精确查询。私有OSS代理不提供学生直链，fetch SSE输出与回放每批查会话／lease和来源策略。访客仅使用本人临时资料／公开内容，不进入账号索引或备份。物理实现、中文质量、撤权并发、清理与外部模型条款按B04／D09实测。
