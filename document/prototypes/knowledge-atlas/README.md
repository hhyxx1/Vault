# 知识图谱交互设计稿

日期：2026-10-08。状态：**供用户评审的设计提案**，尚未接入生产学习数据。

设计说明见 [KNOWLEDGE_GRAPH_DESIGN.md](../../KNOWLEDGE_GRAPH_DESIGN.md)。本稿用于核对课程全景、单元局部关系、证据条件、下一步和手机路径。8 章、16 单元、32 个独立目标只是数据结构的交互样本，不是完整课程范围；跨章引用共 33 条，统计仍为 32。全部状态、关系、帮助和核验记录为模拟，不调用学习 API，不访问账号或学习数据库，不写浏览器存储。

## 查看与操作

从仓库根目录运行：

```powershell
python document/prototypes/knowledge-atlas/serve.py --port 5176
```

打开 [本机交互设计稿](http://127.0.0.1:5176/prototypes/knowledge-atlas/index.html)。服务仅绑定 `127.0.0.1`，不替换 5173 的项目服务。也可使用支持 JavaScript 模块正确 MIME 类型的静态服务器；直接打开 file URL 可能因模块安全限制失败。

建议走查：

1. 全景查看各章四类状态分布，选择“栈与应用”或“继续栈的推演”。
2. 打开“后续应用”，沿关系查看括号匹配与 DFS；点击关系说明查看方向、用途、来源。
3. 在右侧／手机下方查看逐项条件、已有证据与帮助，以及下一步。
4. “预览学习入口”展示理论与尝试交替进行的活动流程；返回后保留选中目标。
5. 用页面底部模拟器依次选择通过、后续冲突，查看状态变化；独立通过记录会保留，邻接目标不会被一起更新。
6. 切换目录视图、状态筛选，或搜索“代价”；同一目标的多处引用共享状态，总分母不变。

URL 保存章节、目标、图／列表、状态筛选、关系开关和模拟事件，支持刷新与返回；不包含真实个人信息。图谱视口与详情展开状态在本页重绘／模拟更新时保留；跨会话完整恢复属于正式产品后续实现。

## 实际验证结果

在安装了项目 Web 依赖与系统 Chrome 的本机执行：

```powershell
node --test document/prototypes/knowledge-atlas/model.test.mjs document/prototypes/knowledge-atlas/ui.test.mjs
```

2026-10-08：**17／17 通过**，其中模型合同 5 项、浏览器交互及截图 12 项，0 跳过。浏览器测试使用隔离上下文，与用户真实档案分开。覆盖：

- 稳定目标 ID 去重、跨章引用、四种状态汇总；模拟结果只更新对应目标，原数据不被改写。
- 全景／局部／列表、筛选分母、搜索空结果、异常章／目标 URL 恢复、刷新及后退。
- 关系类型、应用来源不冒充严格先修、学习入口与返回、模拟通过后出现冲突仍保留成功历史。
- 键盘选择、弹窗关闭、重绘时焦点与详情展开状态保留。
- 1520px 桌面、320×800、390×844、844×390；检查页面无横向溢出、可见图谱节点不重叠。
- 无未处理浏览器异常、无外部／学习 API 请求、无 localStorage 写入。

上述测试证明设计稿的这些行为，不代表正式产品、真实核验、权限或全课程完成。50／150 目标压力样本、200% 浏览器缩放、全面读屏与真实课件长标题仍待正式实现时验收。

## 八维视觉复核

| 维度 | 本次检查与调整 | 后续仍需确认 |
|---|---|---|
| 排版 | 课程名、局部名称、目标与状态分级；说明文字短段显示，长证据收进可展开区 | 更长的真实课程标题与不同字体平台 |
| 留白 | 局部图只围绕当前单元与邻接关系展开；移除整章同时铺满目标的布局 | 更密的真实关系与大课程样本 |
| 视觉层级 | 图谱前置，操作开关移到图谱上方；下一步放在条件之后、证据全文之前 | 用户是否能立即找到下一步 |
| 色彩 | 冷白背景、墨蓝正文、焦点蓝；四状态另用青／琥珀／紫／灰，配文字符号 | 全量对比度及色觉缺陷专项检查 |
| 动效 | 不使用自动漂移／随机力导向；仅短促边框反馈，尊重减少动态效果 | 真实异步核验后的变化提示 |
| 微交互 | 搜索、下钻、回退、关系含义、焦点恢复、明确的模拟核验及重置 | 正式环境的失败／冲突处理 |
| 响应式 | 手机目录折叠，局部图纵向呈现，详情在同页下方；放大主要触摸目标 | 实机浏览器与200%缩放 |
| 原创性 | 根据课程范围、知识关联和证据闭环组织界面；概览与局部网络承担不同任务 | 用户对视觉方向的评价 |

## 正式实现边界

本次新增文件仅位于 `document`，没有替换线上或本机正式 Atlas，也未修改学习状态算法。生产实现需先修正现有课程目录“目标只能出现一次”与 PRD“目标可多处引用但去重”之间的冲突，再将此界面接入真实课程、活动、证据和授权。完整默认课程仍为 **0／13**。
