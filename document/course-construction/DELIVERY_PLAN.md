# 全课程交付与任务分解

状态：可执行建设方案，尚未实施。上位要求见 [索引](README.md)。

## 1 完整交付的含义

13 门全部建设是第一阶段出口，不因分批施工减少最终范围。每课完成全部已确认核心模块：目标与关系、必要理论、可修改作品、实践环境、结果反馈、解释与独立变体、恢复、标准及审校。学生可无教材、未登录开始；在线执行需要网络，本地保存不等于全部离线运行。

完整内容、可运行活动、可靠评估、整课验收分别登记。自动核验、有限模型核验、人工审阅都可以成为明确路径；核心目标缺少任何可实际使用的核验／审阅路径，就不能标记整课完整。人工审阅必须有真实接单人、入口、标准、结果与回访，不以“以后找老师”抵扣开发工作。

没有审阅人员时，可完成可自测的工程包、内容草案和自动判定测试，发布状态停留在相应门槛；开放证明与设计的结论保留待复核。学生本人自述、AI 建议与正式审阅分开记录。

## 3 交付目录约定

以下为拟新增运行内容结构，不代表这些文件当前存在；说明和报告始终放 `document/`。

```text
content/courses/<course-code>/<version>/
  manifest.json             # 课程范围、版本、许可、发布状态
  outline.json              # 章节、单元与目标引用
  objectives.json           # 可观察目标及必要条件
  relations.json            # 类型、方向、理由、来源与审校
  theory/                   # 原创讲解、示例、反例与来源定位
  activities/<activity-id>/ # 题面、初始作品、工具需求、提示、变体配置
  source-map.json           # 来源与本地理论、目标、活动的映射
  compatibility.json       # 与旧版本目标、标准的承接决定
services/backend/.../course_checks/ # 受信核验插件，不接受上传的任意检查程序
document/course-reviews/<course-code>/<version>/
  coverage.csv              # 一行一个目标，分别统计内容、活动、核验、审校
  review.md
  acceptance.md
```

受限答案和隐藏测试独立存放、按任务来源授权，不能随公共清单下载到浏览器。自学允许主动揭示答案，但其变体核验仍应有独立保留题；教师发布按原实例规则控制答案。未登录的个人作品保存在浏览器，服务端临时执行结果按既有访客租约处理；登录承接需按账号方案确认归属。

## 4 每个模块的可分配任务

使用 `B06-CSxx-Mnn-{SCOPE,THEORY,ACTIVITY,CHECK,VARIANT,GRAPH,REVIEW}` 建任务，记录依赖、负责人、预计与实际工时、文件、测试和状态。每一项均可单独评审：

- SCOPE：将逐课方案中 3 个计划目标拆成必要表现；有复合目标时再细分并解释理由。
- THEORY：每目标准备必要概念、一个 worked example、一个误区反例和可追溯来源；长度以能开展活动为准。
- ACTIVITY：提供可编辑初始作品、明确操作、结果与解释入口，不只出选择题。
- CHECK：逐条件写输入、可靠预期、错误样例与未知处理；工具结果与开放解释分别记录。
- VARIANT：提供不同输入、约束或结构的独立核验，记帮助和答案使用；不得只改题面措辞。
- GRAPH：归属、先修／关联／应用、出处、理由及去重引用；对孤点逐个解释，不为好看补边。
- REVIEW：独立核对范围、答案与检查器，签具体版本并记录剩余问题。

## 5 责任与已确认安排

项目发起人决定范围与发布；课程编写者交付内容；学科审阅者核对概念、证明和解法；工程核验者检查工具与测试；发布者检查完整清单。可以一人承担多项，但必须记录实际责任，不能虚构独立审校。目前没有专业审校人；按确认记录允许经核对的内容受限开放学习，缺少可靠复核的结论不能声明独立达标，不能伪造审校通过。

本科核心深度、主语言与扩展边界按[已确认决定](CONFIRMED_DECISIONS.md)执行。CS01 C17、CS02 Java21、CS03 C++17、CS04/11/12/13 Python3.13 为主线；公共运行能力仍建设。GPU 集群、FPGA 实物、厂商认证和研究级编译器列扩展，核心原理及模拟／实操不能因此删掉。以后引入具体学校大纲时登记差异，不覆盖当前核心范围。

硬件采购、付费模型预算、并发上限和审阅服务时限在试运行测量后另定，本方案不授权购买或改动现有服务器。

## 6 先修桥接不能只留一个链接

另建桥接包并关联相关课程入口：BR-JAVA（编译、多文件、类型与集合入门）、BR-CPP（C++17 编译、引用、对象生命周期与标准容器）、BR-PY（Python 语法、数据结构、环境和数值数组）、BR-MATH（向量矩阵、导数梯度、概率、条件概率及统计指标）、BR-SHELL（文件、进程、管道和受控终端）。

桥接包同样交付短说明、可操作任务、检查和恢复；已有能力可直接验证后跳过。它们不是额外声称完整支持的课程，也不进入 13 门各课分母；本课声明的核心目标仍必须在本课完成。运行环境不同不应要求学生先自行安装整套开发工具。
