# 活动、执行与多 Agent 建设方案

状态：拟实施。沿用 [ADR](../ARCHITECTURE_DECISIONS.md)、[网络实验设计](../NETWORK_LAB_DESIGN.md)和[教学 Skill 设计](../SKILL_DESIGN.md)，不另起一套技术栈。

## 1 每一个目标如何变成可学习活动

活动包必须完整包含：情境与问题、必要理论、可修改初始作品、学生动作、执行／观察、解释、标准、帮助、独立变体、恢复和下一步。自由探索不必每次提交；阶段核验使用明确的作品快照。学生可以先读必要说明，也可先尝试再根据错误补理论。

最低交付约定：每目标有可用的理论说明、至少一个承载其必要表现的实践任务、逐条件标准、正确／错误／证据不足样例、分层提示与答案策略、独立变体和继续位置。多个目标可以共享一项活动，但必须记录活动到各目标条件的覆盖，不能以同一个总分替代。

活动实例保存课程／目标／标准版本、输入及 seed、作品 hash、环境 profile、帮助快照、工具 run、结果与解释。恢复先恢复作品及实际条件，再判断环境能否重建；失效的网络／SQL 会话通过版本化模板恢复，不能把旧终端输出当作新环境运行结果。

| --- | --- | --- | --- |
| E01 code | C17/C++17、Java21、Python3.13、Node24；CS01/02/03/04/10/11/12/13 | 独立 Linux VM 原生 isolate，单文件及受控多文件、输入、编译日志、测试结果；实际镜像和补丁验收锁定 | 编译失败／超时／资源限制／环境故障分开；环境故障不计能力错误；取消后回收进程及文件 |
| E02 trace | CS03/04/05/06/07/11/12 | 通用事件轨迹播放器，学生编辑状态和动作，后端纯函数检查器；真值表、结构、指令、调度分别实现规则模块 | 检查中间状态与最终结果；显示模型假设，模拟不能宣称实物或真实内核实操 |
| E03 sql | CS09 | 独立实验 PG18，每活动独立租户／库或受限 schema＋角色；两连接事务调度、数据重置 | 结果集按题面选择集合／多重集／有序比较；检查 NULL、约束、事务结果，不匹配 SQL 文本 |

| E06 data | CS13，部分 CS12 | 隔离 Python CPU 环境，白名单依赖、可复现小数据集、训练与验证工件 | seed、划分索引、预处理拟合范围、模型参数和指标计算都需记录；仅高准确率不能通过 |

每适配器实现 `prepare/run-or-step/inspect/check/snapshot/restore/cancel/cleanup` 语义；不适用的方法显式声明。业务服务只持任务与证据接口，执行控制器不把宿主权限交给学习代码。公开网络实验按已有 ADR 的每租约 VM 边界实施；无专有设备软件时使用通用协议实验，不宣称厂商 CLI 等价。

预算建议仅作为首次压测起点：普通代码运行 5 秒、编译 30 秒、单次输出 1 MiB；内存按语言 profile 分别测试，Java 编译不能沿用 C 的限制。数据实验先限制小数据和 60 秒训练；网络实验先串行单租约测量。全部数值必须经过正确作品、故意超限、取消和并发测试再形成可发布配置；现有服务器是否够用不作假定。

## 3 检查器及参考答案建设

优先使用可独立验证的语义、不变量、状态轨迹、结果集、已知小规模枚举和固定语言规则。参考实现和检查器独立核对；加入会“骗过检查器”的故意错误程序，测试硬编码输出、遗漏边界、只提交最终状态等情况。

确定性检查器输出逐条件 `met/not_met/needs_review` 与依据；工具错误另有 `environment_error`，不能变成 `not_met`。完整答案由自学／教师来源规则决定是否展示，自动评分不能读取被学生修改的标准。模型辅助证明或设计评价输出可追溯建议，不独自把开放论证变为已核验。

## 4 多 Agent 与 Skill 的接入

沿用 PRD 中四项学习职责及按需课程／Skill 设计职责，使用既有 LangGraph 与模型网关。实施前将节点名称和输入输出与现有 Agent 文档对齐，不增加“每课一个常驻 Agent”的要求。

- 规划与诊断：读取课程蓝图、学生意图及有效证据，提出可修改的短期目标；按当前依据安排后续学习，不先要求完整测评。
- 辅导：读取实际作品、错误和帮助历史，引用当前任务的理论，给下一步可操作提示，并把操作交回学生。
- 实践任务：选择或生成适合的任务、反例和项目步骤，附目标映射、测试和标准；生成内容经核对后才能用于可信核验。
- 核验：调用已授权适配器及审阅流程，分别核验功能、解释与迁移；判断附工具事实或审阅结果，不能把生成日志当作执行日志。

上述名称与 PRD 第 8.1 节一致。课程与 Skill 设计职责生成草案，必须走内容审校与版本发布。教师／学生自带声明式 Skill 可调整教学方法，不可改答案权限、工具能力和核验标准。

各课至少提供一个教学方法 Skill 草案，如反例引导、状态跟踪、SQL 差异定位、网络故障分层、模型泄漏检查；每个 Skill 交付适用前提、输入、步骤、输出、预算、失效条件和测试。自动生成 Skill 先私人试用再独立核对，不直接进入默认课程发布包。

开源版模型按职责配置，至少对两种独立模型配置执行相同样例回归；支持用户自定义服务与模型。没有凭据时可完成工具和契约测试，但真实多 Agent 教学质量、延迟与成本仍为发布前待测。不得把模拟模型通过视为真实模型联调完成。

## 5 教师、访客与资料

同一课程包可进入自学或教师发布实例；学生可见资料才进入学生 RAG，教师私有 PPT、备注和源切片不进入学生上下文。独立发布物保留授权谱系，答案限制仍按原任务实例检查。访客本地、登录关联、账号切换、教师授权和撤权对作品、图谱、检索及缓存一起测试。
