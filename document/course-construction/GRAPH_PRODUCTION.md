# 知识图谱生产与展示编排

承接 [图谱总方案](GRAPH_PLAN.md) 和 [122 模块编排](MODULE_SEQUENCE.csv)。这是课程语义数据及展示的施工要求，不是另做一个只有节点动画的演示。

## 1 每课的一批交付

1. 按课程文件模块表建立完整目录；把复合模块拆成知识单元，写清单元名称及其活动。模块及单元是导航层，不直接计作掌握目标。
2. 将该课全部计划目标映射到稳定 ID；已有 CS03/CS05 目标逐条承接或补验，禁止按名称直接覆盖。
3. 每个目标填写可观察表现、必要条件、适用模型、活动入口和来源记录。一个目标放一个主归属，其他单元只引用。
4. 逐目标审查完成其活动需要什么能力；候选关系逐条核对，未确定的关系不进入正式导航建议。没有边可以成立，但必须解释孤点是否漏编排。
5. 给所有目标填实际内容、活动、核验状态；用独立测试空间验证证据更新。生产用户没有证据时维持未评估。
6. 从同一课程版本生成总览、局部和列表；三者核心目标集合及分母一致，筛选只改变可见范围。

## 2 关系审查表

未来每课交付 `graph-review.csv`，每目标至少一行审查记录；有多条候选关系则多行。字段：

`objective_id, unit_id, criterion_ids, activity_ids, related_id, relation_type, direction, necessary_condition, source_claim_ids, decision, rationale, reviewer_kind, course_version`

`decision` 区分待核对、采用、拒绝、无需关系；无边时 related_id 可空并填写理由。严格先修的 necessary_condition 必须说明后者哪项条件依赖前者哪种能力。推荐学习顺序单独保存在 sequence 中，不混入 relation_type。

| 候选情境 | 应如何审查 | 不应生成的结论 |
| --- | --- | --- |
| 链表与链式队列 | 队列当前实现确实使用链接操作，可列应用或针对该实现的先修 | 所有队列都必须先学链表 |
| 栈与括号匹配 | 对采用栈的活动列应用关系，并说明保存未闭合项 | 栈已掌握则括号匹配自动达标 |
| 图遍历与拓扑排序 | 说明使用的算法；推荐关联不等于唯一必要方法 | 目录中先出现就设严格先修 |
| IP 路由与 TCP 实验 | IP 连通是当前端到端实验所需能力，分清活动条件与协议定义 | 所有应用协议必须经过 TCP |
| 集合与 SQL | 连接概念时同时标注 SQL 多重集和 NULL 条件 | 把集合恒等式直接当全部 SQL 行为 |
| 线性代数与机器学习 | 指向所需向量/矩阵操作桥接，不强制整门数学课 | 点击数学链接就计入本课掌握 |

以上是审查例子，不是已经批准的全部边。实际边必须由活动和已读来源落实后发布；不能为了让画面像设计稿而补造关系。

## 3 CS03-M03 的目录布局样例

```text
数据结构
└─ M03 栈与队列
   ├─ U01 栈状态与边界 ── O01 对应条件
   ├─ U02 循环队列 ───── O02 的先进先出/回绕条件
   ├─ U03 链式队列 ───── O02 的链接与边界条件
   ├─ U04 括号匹配 ───── O03 对应条件
   └─ U05 独立迁移 ───── 引用 O01/O02/O03 的适用条件
```

总览显示模块及覆盖计数；进入 M03 显示单元及三个唯一目标，U05 的引用不得令分母从 3 变成 6。选 O02 时详情要显示循环与链式实现分别有哪些证据，避免“一个队列题正确”覆盖全部条件。

局部视图显示选中目标、其直接关系和必要的跨模块引用；例如链表引用保留 M02 归属。没有完整三组关系时自适应居中，不用空白列伪造缺失内容。节点布局和过渡沿用已批准原型的风格，实际关系数决定布局，不照抄示例位置。

## 4 学生能直接看懂的状态

详情分四行报告：

- 内容：待建设／待核对／可学习；专业审校情况另示。
- 实践：可开始／可继续／环境暂不可用。
- 核验：哪些条件可自动判定，哪些待复核或尚无可靠路径。
- 自己的进度：未评估、已满足的条件、待补的证据及独立变体入口。

课程总览报告“已有独立达标证据 x/y”“可实践 a/y”“可可靠核验 b/y”，说明各自计算条件。不能将看过理论、跑过一次或揭示答案折成知识掌握比例。动态效果只解释选择、展开和关系变化；只有真实证据变化才改变学习状态。

## 5 每课必须完成的六个走查场景

1. 新访客打开整课：所有核心目标可发现，未建成节点明示状态，无假进度。
2. 从跨章引用跳到目标再返回：归属、选中状态、滚动和过滤条件可恢复。
3. 一个条件通过、另一个待复核：模块不全亮，右侧能看到证据缺口。
4. 查看答案后完成原题：保留帮助标记，下一步进入独立变体。
5. 环境不可用或课程版本变化：历史证据不丢，当前限制和补验要求明确。
6. 切换课程、账号或教师可见范围：计数、证据与私有来源不串用；手机及键盘路径均可操作。

在数据制作阶段先验证引用、重复、先修环和状态计算；进入实现阶段再运行实际浏览器交互和截图对照。当前文档检查不能记作六场景已经通过。
