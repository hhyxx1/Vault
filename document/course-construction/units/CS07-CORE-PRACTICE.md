## 执行及证据边界

真实 API 任务使用 Linux 非 root isolate 用户。所有创建的描述符关闭，父进程 waitpid 回收子进程，线程 join 结束；资源限制仅降低本沙箱进程的软限制。进程退出数值七的等待状态字为1792，不能当成退出码。丢失更新通过 Barrier 确定交错复现，锁覆盖读改写修正；单一交错不证明全部并发路径。权限拒绝使用真实 chmod，不拿模拟字符串伪装系统错误。

trap/return、调度、死锁、页表、置换、磁盘和 ACL 是原创教学模型。未运行 strace，不声称具备真实内核调用 trace。分页模型不意味着修改真实页表；磁盘模型不意味着当前存储设备的实测寻道。FIFO 命中不刷新次序，LRU 刷新。工作集注明最近三次访问窗口，不从累计访问数推断抖动。

银行家反例总资源为4，allocation=[1,1,1]、available=1，每个 max≤4；完成后只归还 allocation。Need≤Work 包括相等条件。UIC 讲义某一步写严格小于，不能照抄漏掉等量可满足情况；声明最大需求超过总资源的非法输入也不能作为安全性核心反例。不安全与实际当前死锁分开。
