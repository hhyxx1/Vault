# CS01 M08：复合记录与多文件接口

当前公共包 `CS01-core-practice-0.8.0` 保留三个活动版本，16 个作者工件通过真实 C17 isolate 执行，桌面与移动浏览器均完成多文件修改及恢复。

O01 按两条结构记录分别读取学号与分数，修复重复第一条导致的错误总分；零分记录不能被丢失。O02 使用 main.c、record.h、record.c、display.c，修复构造器忽略参数的问题，再只替换显示模块。实际编译各 C 实现，不通过文本拼接伪装多文件构建。头文件具备包含保护，显示接口使用只读指针，编辑器分别选择各文件。

O03 明确分数约束 0–100；先写字段后拒绝的错误会破坏原记录。学生修复为修改前验证，实际检查 101、-1、0、100，拒绝时学号和原分数保持不变。

来源核对 [WG14 N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)：6.5.2.3、6.7.2.1、6.10.2。专业审校未完成。结构体布局、通用序列化、任意共享状态及 ABI 不在本次输出核验范围内。

目标解释与独立迁移仍待复核，固定条件符合不代表独立接口设计能力。复现脚本 `tools/curriculum/build_cs01_records.py`；作者工件 `services/backend/fixtures/course-code/CS01-records.json`。
