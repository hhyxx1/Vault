## 真实执行范围

IPv4 回环通信仅在每次 isolate 的私有网络命名空间内完成，不添加 share-net，不修改宿主网络、不访问外网。TCP 服务 bind 到内核分配端口，线程结束、socket 关闭，读操作有超时；真实 shutdown(SHUT_WR) 与 EOF 后仍读取响应。UDP recvfrom 的缓冲区不足会截断当前报文，下一次接收的是下一报，不把流语义套到数据报。

本地 DNS 任务仅收发 12 字节头并核对 ID/QR，没有完整域名问题、RR、压缩或递归，故不能冒称已完成 DNS 解析。HTTP 任务仅解析本例明确的 HTTP/1.1 close 响应，不支持通用分块等情况。重建只是两个回环服务实例，未完成 containerlab/FRR 双网段恢复。

其他协议活动明确为原创有限模型，不把 Python 字典、布尔值或图算法当成网络设备操作。VLAN 分区的学习目标仍要求真实禁止通信证据，ping 一次成功不能替代。
