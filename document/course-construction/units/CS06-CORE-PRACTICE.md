## 原创模型规格

- 整数 ALU：八位无符号保存低八位，单独解释补码；不冒称 C 有符号溢出语义。
- 舍入：Fraction 精确输入、最近且中点取偶；p=3 含隐含首位，规范化指数 e 区间间距 2^(e-(p-1)) 是原创新模型推导，不是 Python float 的三位精度配置。零、次正规、无穷与 NaN 尚未编码。
- 状态：同上升沿使用旧状态；复位同步且优先于使能。这是本题规格，不能推广所有硬件。
- 教学 ISA：16 位编码，15..12 为 opcode、11..0 为无符号 immediate；字寻址。暂只有独立字段及操作片段，不能宣称可运行完整指令程序；不兼容 Hack、RISC-V 或 x86。
- 存储端口：本题读写互斥；不能用此规则否定其他双端口语义。
- 流水线：教学五级顺序执行，加载 MEM 末可用；转发例只比较来源，不含完整周期调度。理想周期 N+4 前提为等周期、无停顿。
- 缓存：字节地址、4 字节块、4 组直接映射；写回工件是单槽模型，虚实转换是独立页表模型，勿混作缓存索引。
- I/O：每拍最多4字节；性能工件 CPU/DMA 全程独立重叠且无启动开销，取 max。实际总线与设备必须另给开销规格。
