# 逐目标测试、整课审校与发布方案

状态：测试建设计划，没有预填通过记录。依据[既有课程验证](../COURSE_VALIDATION_PLAN.md)和[综合测试计划](../TEST_PLAN.md)。

## 1 台账必须能追到一个目标

`coverage.csv` 字段：course_version、module_id、objective_id、core_or_elective、criteria_ids、theory_refs、activity_ids、environment_profiles、checker_or_review_route、normal_case_ids、wrong_case_ids、variant_ids、source_refs、reviewer、review_date、test_run、blocking_issue、content_state、activity_state、assessment_state。

发布前核心目标所有字段适用项完整；不适用必须有审阅理由，不能用空字符串通过检查。检查器测试、UI 导航测试、教研覆盖审阅分别计数，不能汇成一个“学习有效率”。

## 2 每活动的测试集合

| 集合 | 必须检查 |
| --- | --- |
| 正确作品 | 标准解和至少一种适用替代解；开放任务有不同合理方案 |
| 故意错误 | 至少两种有教学意义的错误；逐项映射到必要条件，核对反馈定位 |
| 边界条件 | 空、最小、最大／资源边界、非法输入及题面特有边界；不适用记理由 |
| 证据不足 | 只有结果无过程、无法复现、来源不明、解释缺失；不得误通过 |
| 帮助与变体 | 分层提示、看答案后完成、新输入／结构／约束下的独立尝试 |
| 环境失败 | 排队、不可用、超时、取消、断连、租约失效、清理失败；不写成学生不会 |
| 恢复与版本 | 修改作品后旧结果失效、刷新恢复、标准更新、重复／迟到事件 |
| 权限 | 访客与账号关联、跨账号隔离、教师授权、受限答案及私有 RAG 内容 |

先用已知正确与故意错误样例验证检查器本身，再允许它评价学生作品。开放证明和设计由真实审阅者测试合理替代方案和争议复核；不能把模型自评分作为唯一金标准。

## 3 图谱专项

每门课全量检查层级与引用、目标唯一性、严格先修无环、关系来源、孤点理由、核心／扩展／个人范围、活动入口和必要条件。选择目标、筛选和缩放后分母保持；跨课程跳转不传播掌握；未知、待建设、环境故障、待复核分别显示。

构造可追溯测试证据验证未评估→部分满足→独立达标→新反例需巩固；只影响相关目标。测试证据使用独立测试空间，不进入用户真实记录。课程增删目标要核对历史映射和新增补验；旧样例证据不得被整包替换静默丢弃。

在 390、734、1520 px 视口和键盘路径下检查长标题、稀疏关系、跨章关系、平滑过渡及减少动效；截图与交互测试共同复核，尺寸通过不能代替视觉验收。

## 4 每课发布门

| 门 | 通过条件 | 不能用来替代的内容 |
| --- | --- | --- |
| Q0 范围审阅 | 本课全部模块、深度和目标经确认，有来源和责任人 | 课程名字或代表性单元 |
| Q1 内容完成 | 所有核心目标的理论、活动、标准、提示、变体与图谱完成 | AI 一次批量生成 |
| Q2 工具及核验 | 所有必需活动实际运行，全部适用测试通过，开放审阅路径可用 | 模拟日志或只测标准答案 |
| Q3 课程体验 | 每目标至少完成一轮真实的尝试／反馈路径；全部模块及综合任务检查跨会话继续 | 只测试一个活动类型 |
| Q4 教研复核 | 概念、答案、边界、替代方案、图谱关系和标准签署具体版本 | 模型之间相互赞同 |
| Q5 发布运行 | 权限、迁移、真实模型配置、容量、恢复与撤回达标，问题清单无阻断 | 本地 UI 测试通过 |

“每目标一轮”是内容工程走查，可以由作者／测试者分担，不要求项目发起人从头学完 13 门。发起人真实学习一门课的长期测试另行记录，不能代替其他课程验收或证明学生群体学习效果。

公式：内容覆盖率＝完整交付目标数／确认核心目标数；评估可用率＝有实际可用评估路径的目标数／同一分母；整课完整＝Q0–Q5 全通过。只有 13 门均完整才达到本次全量建设目标。未完成课程可以清晰标注预览，但不能计入完整交付。

## 5 审阅记录和变更

报告逐课保存课程及环境版本、检查器／模型／工作流／Skill 版本、测试命令、实际结果、工件位置、审阅者和日期、阻断项及整改。私有作品、完整模型凭据、受限教材原件不入 Git；报告引用授权范围内的匿名样例。

内容修改重跑对应目标及依赖活动；检查器或环境修改重跑所有使用者；统计、权限或恢复机制修改需在 13 门入口检查公共回归。发布清单不可变，回滚恢复到明确版本；发生错误评价时撤回相关结论并通知受影响学习空间，保留历史与理由。
