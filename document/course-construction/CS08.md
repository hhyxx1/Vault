# CS08 计算机网络建设方案

状态：本科核心建设范围已确认；尚未构成已审校课程。下列模块进入建设范围，编写中继续查漏和核对深度。

## 1 范围、先修与环境

- 先修与补充：CS01 基本程序和终端；位运算、计时与概率按需补充。
- 环境：E05 containerlab/Linux/FRR、E02 协议推演、E07 解释。适配器契约见[执行方案](ACTIVITY_ENGINE_PLAN.md)。
- 综合产物：双网段服务网络的建设、故障定位与重建。
- 当前计划：10 个模块、30 个可观察目标。数量是本方案的工作分解，不是已验证的学科覆盖结论；审阅发现遗漏须补齐。
- 无教材入口直接使用经审阅默认包；上传教材或教师大纲只改变来源映射与可选路线，不成为开课前提。

## 2 模块、目标与实践清单

每行目标依次编号为该模块 O01/O02/O03。例如 M01 的第一项目标是 CS08-M01-O01。下列活动是模块主任务；编写时须将三个目标的必要条件分别映射到作品、解释或独立变体，未覆盖的目标必须追加子任务。

| 模块 | 三个计划目标（依次 O01–O03） | 主活动与学生动作 | 核验方式及必须检出的错误 |
| --- | --- | --- | --- |
| M01 分层与性能 | 解释分层封装；计算传输传播时延；区分吞吐和带宽 | 解析一条请求跨层路径并计算链路瓶颈 | 字段和单位核对；往返与单程混淆为错误样例 |
| M02 链路与差错 | 推演帧边界；计算校验及重传；解释介质访问限制 | 修改模拟帧及差错条件 | 按明确规则核验；不把教学模型当真实物理信道 |
| M03 以太网与交换 | 观察 MAC 学习；配置二层连通及 VLAN；定位广播与环路问题 | 浏览器终端配置隔离网桥和 VLAN | 真实转发表与分区通信；能 ping 不证明隔离正确 |
| M04 IP 与地址 | 规划 IPv4 子网；解释 IPv6 地址及邻居发现；配置接口和网关 | 建立两个子网并处理重复地址 | 接口快照、正反向测试与报文；错误掩码必须检出 |
| M05 转发与路由 | 匹配最长前缀；配置静态路由；观察动态路由收敛 | 在 FRR 小拓扑注入断链并恢复 | 路由状态及多方向流量；不以配置文本替代生效状态 |
| M06 网络控制与边界 | 观察 ARP/ICMP；解释 MTU 和分片条件；配置受控 NAT 与过滤 | 定位网关可达但服务不可达的问题 | 限定链路抓包和状态；不得探测外部网络 |
| M07 传输层 | 追踪 TCP 建连关闭；解释重传流控和拥塞；比较 UDP 语义 | 在隔离链路改变时延和丢包并抓包 | 序列号、窗口与应用结果；不能用 TCP 状态推定应用成功 |
| M08 应用协议 | 观察 DNS 解析；解释 HTTP 请求响应；区分 TLS 与应用授权 | 搭建隔离名称服务和 Web 服务 | 服务日志及查询响应；错误 DNS 与端口分开定位 |
| M09 无线与安全基础 | 分析无线共享介质；区分加密认证完整性；识别协议攻击面 | 对给定报文和无线情境进行推演与配置评审 | 结构化场景及人工审阅；无线物理实验另列扩展 |
| M10 综合排障与恢复 | 按层提出可检验假设；用证据缩小故障；重建并验证拓扑 | 修复双网段服务并导出恢复包 | 配置、状态、定向 pcap、解释和变体；不依赖 eNSP 或 Cisco 软件 |

## 4 综合任务的完整闭环

题目：交付“双网段服务网络的建设、故障定位与重建”。从可修改的初始工件开始，学生先解释关键假设、预测一次结果，再实际操作。

1. 规划：选择两个相邻模块，明确本次产物和必要条件；已有基础可直接提交作品核验。
2. 尝试：保存作品快照并运行对应工具或提交推演；出错后展示实际差异，链接到对应理论，而非直接代写正确作品。
3. 修正：学生修改并解释原因，再执行；保存失败与成功历史、帮助及答案使用。
4. 独立变体：改变“子网规划、路由故障、MTU、丢包与服务端口变化”；按适用条件设计保留任务，不能复制已揭示答案后就判独立达标。
5. 恢复：退出后恢复作品、活动版本、帮助和下一步；失效环境须重建并重新取证。
6. 汇总：每个必要条件分别反馈；开放解释交真实审阅流程，工具失败保留未核验。图谱只更新实际适用目标。

综合任务验收须列模块覆盖表；本任务未覆盖的模块仍需逐行主活动验收，不能凭综合任务成功宣布全课通过。
