# 可直接展开实现的活动契约样例

状态：建设规格，不是已经运行的实验；示例中的结果均为预期，需独立核对并实测。完整字段沿用[课程包规范](../COURSE_CONTENT_SPEC.md)。

## 1 CS08：双网段服务不通

映射：CS08-M04-O03（接口和网关）、CS08-M05-O02（静态路由）、CS08-M10-O02（证据定位）。工具 E05，公开租约按独立 VM 隔离。

固定模板：浏览器内呈现 A—R—B；A 为 `10.10.1.2/24`，R 两端为 `10.10.1.1/24`、`10.10.2.1/24`，B 为 `10.10.2.2/24`。B 提供固定实验 HTTP 服务，平台外网络默认不可达。初始故障为 B 缺少回程路由；该答案按自学或教师发布策略控制。

学生先预测 A 发起请求经过哪些接口，再查看状态并修改路由；提交配置、一次失败和修复后的实验结果、抓包片段以及解释。AI 可以提示检查回程，但不能自动替学生提交配置后宣布掌握。

| 必要条件 | 受信核验输入与预期 | 不满足／未知示例 |
| --- | --- | --- |
| 地址与接口 | 从运行节点读取接口、地址和链路快照；与任务地址约束相容 | 仅上传一张拓扑图片，保持未知 |
| 双向路由 | A→B 与 B→A 的受控探针及路由查询，路径能满足该拓扑 | 仅 A 能 ping R，不能通过 |
| 服务结果 | 从 A 请求 B 固定测试资源并核对响应；检查未授权网段仍被隔离 | ICMP 通但 HTTP 服务未启动，服务条件不通过 |
| 解释 | 学生说明请求和回程、故障证据及修改理由，由 rubric／实际审阅判定 | 复制命令而无法解释回程，自动条件与解释分开 |
| 独立变体 | 改用任务内预生成的新子网，或将故障改为错误网关；保存新的输入及帮助范围 | 重放旧成功日志不能通过新实例 |

保存 `topology_version, lease_id, config_snapshot, interface_snapshot, route_snapshot, probe_results, pcap_ref, artifact_hash, help_snapshot`；pcap 仅捕获实验链路，限制字节数和时长。终端操作用于回顾，最终核验从运行环境独立取状态，不以历史命令是否包含某字符串评分。

恢复：保存配置后结束租约；重新进入时重建拓扑并回放学生配置，显示新运行编号并重新探测。模板、镜像、配置任一变化都不得沿用旧运行成功作为新结果。工程测试至少包括缺回程、错掩码、关闭服务、链路断开、工具超时、取消和清理；正常配置及等价有效路由各一例。

## 2 CS09：并发订单导致库存错误

映射：CS09-M07-O01/O02/O03。E03 独立实验库，两会话受控调度。初始 `stock(sku PRIMARY KEY, qty CHECK(qty>=0))` 只有一件商品，两个订单分别请求一件；订单标识唯一。学生实现事务并解释选择的并发控制方式。

调度器在两个会话完成指定步骤后使用屏障放行，重现竞争，不依靠固定睡眠。核验应接受行锁或合适的条件更新方案；在符合题面隔离要求的前提下，不按 SQL 文本匹配唯一答案。

必要结果：最多一个订单确认；库存不能负数；确认订单与库存扣减一致；失败请求不留下已确认订单；重试不重复扣减。注入订单写入失败后，库存回滚。保留 SQL、参数、事务边界、屏障轨迹、错误、最终表快照和解释。

错误样例：先读后写但不控制竞争；只保护库存而订单不在事务内；重复请求创建两单；吞掉数据库错误仍返回成功。独立变体改库存、购买数量和重试顺序。开放的隔离级别取舍需要解释审阅，结果正确不覆盖所有设计条件。

## 3 CS05：数学归纳论证

映射：CS05-M03-O03。学生证明任务给定的求和命题，提交基例、归纳假设、归纳步骤及变量适用范围。参考论证和常见错误先由学科审阅者核对；参考答案是否可见按任务来源规则执行。

自动检查可以验证表达式、给出有限范围的反例、检查填写结构；这些都不能独立证明一般命题。rubric 逐项检查基例覆盖、假设使用无循环、推导等价、范围闭合和结论。合理的另一种证明允许按对应标准审阅，不强制套归纳模板。

缺少基例、把结论直接当假设、有限枚举冒充一般证明、除以可能为零的式子均作为错误样例。无真实审阅时显示“程序检查已完成，论证待复核”，不增加完整达标数。独立变体改变命题结构或增加条件，并记录是否需要新的证明方法。

## 4 CS13：修复数据泄漏

映射：CS13-M02-O01/O02/O03、M09-O01。固定一个许可清楚的小数据快照和分割清单，初始程序错误地在全量样本上拟合预处理器。学生修改流水线、重跑，并说明为什么原指标不可信。

核验读取样本 ID 集合、预处理拟合范围、训练与评估调用工件；检查集合互斥、转换器只在训练数据拟合、标签和列没有泄漏、指标能由预测及真实标签重算。不要设置“修复后分数一定提高”的通过条件。

独立保留集仅在正式核验阶段使用；自学答案可展示方法和练习集，但不能让保留集反复充当调参依据。错误样例包括只修改注释、训练测试索引重叠、在划分前拟合、指标分母错误。结果字段还需记录 seed、依赖版本和容差；CPU 环境失败保留未核验。
