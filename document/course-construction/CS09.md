# CS09 数据库建设方案

状态：本科核心建设范围已确认；尚未构成已审校课程。下列模块进入建设范围，编写中继续查漏和核对深度。

## 1 范围、先修与环境

- 先修与补充：CS01 数据处理；集合、关系和逻辑补充。
- 环境：E03 PG18 独立实验库、E07 设计审阅。适配器契约见[执行方案](ACTIVITY_ENGINE_PLAN.md)。
- 综合产物：带库存和订单事务的课程书店数据库。
- 当前计划：10 个模块、30 个可观察目标。数量是本方案的工作分解，不是已验证的学科覆盖结论；审阅发现遗漏须补齐。
- 无教材入口直接使用经审阅默认包；上传教材或教师大纲只改变来源映射与可选路线，不成为开课前提。

## 2 模块、目标与实践清单

每行目标依次编号为该模块 O01/O02/O03。例如 M01 的第一项目标是 CS09-M01-O01。下列活动是模块主任务；编写时须将三个目标的必要条件分别映射到作品、解释或独立变体，未覆盖的目标必须追加子任务。

| 模块 | 三个计划目标（依次 O01–O03） | 主活动与学生动作 | 核验方式及必须检出的错误 |
| --- | --- | --- | --- |
| M01 关系模型与代数 | 定义关系键和约束；推演关系代数；区别集合与多重集 | 从小数据推导查询再验证 SQL | 结果语义；错误样例丢重复或误处理 NULL |
| M02 概念与逻辑设计 | 绘制实体联系；转换关系模式；选择主外键和约束 | 建模图书订单和库存 | 约束反例与设计审阅；图画得完整不等于模型正确 |
| M03 基本 SQL | 实现筛选投影排序；修改数据；建立和验证约束 | 完成数据导入与查询 | 真实执行、类型与顺序要求；无 ORDER BY 不强制顺序 |
| M04 连接与聚合 | 实现多表连接；处理分组聚合；使用子查询与窗口 | 统计无订单用户及分组排行 | 包含空集、NULL、重复键；反例为内连接遗漏零值组 |
| M05 规范化 | 求函数依赖闭包；判断范式；验证分解无损及保持依赖 | 修复冗余模式并构造异常 | 有限计算加一般论证审阅；样例数据不能证明所有依赖 |
| M06 索引与执行计划 | 选择索引；解释执行计划；比较扫描与连接代价 | 固定数据上调整索引与查询 | 计划和实际结果；耗时不作为唯一判据 |
| M07 事务与并发 | 编写原子事务；重现隔离异常；处理锁与冲突 | 双会话执行并发下单 | 调度屏障及最终约束；不使用不稳定 sleep 控制时序 |
| M08 恢复与日志 | 解释日志先行原则；推演撤销与重做；验证事务回滚和数据恢复 | 在独立测试环境重放故障轨迹 | 日志模型或真实恢复分别标识；不能破坏业务库 |
| M09 权限与程序接口 | 设置最小权限；参数化查询；维护视图和应用边界 | 修复越权查询及注入风险 | 受限角色真实访问测试；不把隐藏 UI 当权限 |
| M10 综合与现代数据 | 完成模式演进；说明复制分片及非关系模型取舍；交付可恢复数据项目 | 新增库存字段并保留订单约束 | 迁移、事务和恢复；分布式原理保留建模范围，不冒充集群实操 |

## 4 综合任务的完整闭环

题目：交付“带库存和订单事务的课程书店数据库”。从可修改的初始工件开始，学生先解释关键假设、预测一次结果，再实际操作。

1. 规划：选择两个相邻模块，明确本次产物和必要条件；已有基础可直接提交作品核验。
2. 尝试：保存作品快照并运行对应工具或提交推演；出错后展示实际差异，链接到对应理论，而非直接代写正确作品。
3. 修正：学生修改并解释原因，再执行；保存失败与成功历史、帮助及答案使用。
4. 独立变体：改变“NULL、重复行、并发下单和模式演进”；按适用条件设计保留任务，不能复制已揭示答案后就判独立达标。
5. 恢复：退出后恢复作品、活动版本、帮助和下一步；失效环境须重建并重新取证。
6. 汇总：每个必要条件分别反馈；开放解释交真实审阅流程，工具失败保留未核验。图谱只更新实际适用目标。

综合任务验收须列模块覆盖表；本任务未覆盖的模块仍需逐行主活动验收，不能凭综合任务成功宣布全课通过。

## 5 内容、来源与审校任务

按本课每个 Mnn 建立 SCOPE/THEORY/ACTIVITY/CHECK/VARIANT/GRAPH/REVIEW 七项任务，执行[任务分解](DELIVERY_PLAN.md)。每个目标至少提供必要概念、可追溯说明、正确示例、误区反例、实践、标准、提示和独立变体。

来源工作由内容作者先登记候选公开大学大纲、合法教材的章节定位和工具官方规范；学科审阅者核对覆盖与正确性。未实际查阅的页码和来源不能预填为已核对。CS2023 知识领域用于查漏，不直接当本课教材。公开课程文本采用原创整理或许可允许的材料，私人教材原件不提交 Git。
