# 数据结构 0.3.0 课程交付与验证记录

日期：2026-10-13。课程版本：`fec2a271-becf-509b-9d1a-16131858f763`。

## 交付口径

本版提供 10 个模块、30 个目标的工程学习版本：理论依据、可执行任务、修错工件、从零实现、新条件、多输入核验、版本保存、连续导航和图谱证据反馈。不是专业审校签字、真实学生完成整课、真实模型联调或生产部署证明。专业审校尚未安排，整课正式验收保持未通过。

## 学习操作闭环

从图谱选择目标 → 阅读任务、预测结果 → 修错或选择从零实现 → 编写并真实运行 → 查看具体反馈并新建修订 → 独立多输入核验 → 写解释、尝试新条件 → 登录同步后申请审阅 → 教师查看冻结作品并逐项判断 → 图谱反映有效证据 → 继续下一目标。查看参考答案记录帮助，不算独立完成。

每个目标有独立活动版本；核验按作品修订 ID 和内容指纹绑定。环境错误不覆盖旧有效结论，新作品不继承旧通过结果。本地学习不要求登录；登录同步和教师关联沿用账户闭环。人工审阅状态需在线获取服务端记录，本地导入文件不能生成教师权威。

## 内容边界和正确性控制

- M01–M03：ADT 契约、逻辑/存储表示、计数、顺序表和链表完整操作、栈、循环/链式队列、括号匹配。M01 顺序型接口与 M06/M09 唯一键集合不同，不混同为同一种 ADT。
- M04–M06：朴素匹配/KMP、COO 稀疏矩阵与广义表树、一般树和二叉树遍历、实际 Huffman 编解码、BST 插删、AVL 旋转、三阶 B+ 树增量分裂/借位/合并。B 树与 B+ 树区别另需解释审阅；教学实现不是生产索引引擎。
- M07–M09：图表示、BFS/DFS、实际最小生成森林边证据、Dijkstra/Bellman–Ford、拓扑排序/关键路径、开放寻址/墓碑/再散列。图输入允许自环时明确不是简单图；负边算法条件、不可达点、分量和负环按任务协议判定。
- M10：六种排序、记录身份和稳定性、真实文件分块/多轮合并、可检索资料目录和路径导航综合项目。外排内存计数限定数据记录，不把文件名等管理开销假称为零。
- 所有程序使用任务明确的有限输入协议，不能据此宣称任意输入下普遍正确。复杂度计数是观察证据，不能替代复杂度证明。
- 非唯一结果使用语义比较：Huffman 前缀码与最优代价、合法拓扑序、合法 BFS/DFS 顺序、真实最小森林边、稳定记录排序和综合项目文件回读。
- 隐藏输入仅留在服务端，成功/失败/环境故障响应不暴露隐藏 stdin、预期或实际输出；样例硬编码程序由独立输入检出。

## 知识图谱规则

维持原设计稿的图谱页面和统一视觉样式，新增版本选择与审阅桥接，不重画已确认设计。知识结构、先修关系与活动目标同版本。未知表示没有可用证据；失败提示巩固；固定条件/多输入通过最高为部分达成；完整掌握需要原理解释与独立迁移有效审阅。所有 30 个目标作为分母，不按任务变体重复计数。

教师批准必须来自经验证教师、对应账户/课程/目标/活动/冻结修订，三个标准均满足；代码作品还必须有服务端真实执行满足记录。异议撤回完整掌握投影。测试教师是合成测试身份，不能当成专业审校。
