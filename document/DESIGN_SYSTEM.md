# 前端视觉实现基准

2026-10-09。固定参考为 `prototypes/knowledge-atlas`，未经用户明确要求不另换图谱视觉方向。

| 项目 | 基准 |
|---|---|
| 字体 | Segoe UI、Microsoft YaHei UI、PingFang SC、sans-serif |
| 背景／文字／辅助文字／边框 | #f5f7fb / #192941 / #64718a / #dfe5ef |
| 主操作 | #315fe7，悬停#214dcd |
| 达标／部分／巩固／未知 | #16826b / #a56a1a / #8852a7 / #7a8597 |
| 标题／区块／正文／辅助 | 31 / 21 / 13 / 10–12px；手机主标题28px |
| 主工作区 | 最大1740px，桌面30px内边距；1520px图谱208／956／294三栏 |
| 面板／按钮／节点圆角 | 图谱工作区13px，普通面板9px，按钮7px，目标卡9px |
| 行动面板 | 背景#edf3ff、边框#dde6fc、14px内边距 |
| 控件 | 桌面主操作40px，手机触控至少44px；图谱关系与辅助控件使用原稿的紧凑尺寸 |

`src/frontend-refresh.css`维护共同样式；`src/ui/atlas-map.css`维护图谱结构与响应式。旧版三栏、圆形网络与后续覆盖规则已从共同样式移除，避免重复图谱布局互相影响。编辑器和Cytoscape有独立主题时，也使用这里的颜色与字体。

全景展示章节及单元归属，不用装饰连线暗示先修。局部图绘制当前目标的直接声明关系；同单元和跨章引用不增加整课分母。必要表现、来源和证据明确分开，关系不继承掌握状态。

每次图谱调整应在同一窗口尺寸比较原稿与实现，至少覆盖全景、栈目标、顺序表未建活动、CS05无完整章节和390px手机。页面风格变更需跑九页面宽度矩阵及学习保存／核验行为回归。截图与当前核对结果见 `ATLAS_DESIGN_COMPARISON.md`。截图相似和自动测试通过均不能替代真实学习、用户视觉评审和完整产品验收。
