# 知识图谱正式前端接入记录

日期：2026-10-08。依据：[知识图谱设计](KNOWLEDGE_GRAPH_DESIGN.md)及其交互设计稿。

## 实现范围

入口、课程、工作台、证据、个人课程、教师备课、本地空间和账号使用统一的冷白背景、墨蓝文字、焦点蓝操作与四类证据状态。默认课程图谱进一步采用左目录、中间关系图、右证据详情的共享界面。CS03 与 CS05 共用课程包驱动的界面；没有目录的 CS05 只显示已声明目标，不编造章节。其他默认课程保留明确的建设状态与个人课程入口。

CS03 的 8 章、16 单元、32 个目标仍是未审校范围样例，不是完整课程。当前仅栈推演提供确定性核验，括号匹配只提供代码作品编辑与保存；CS05 提供固定四行真值表核验。其余目标在详情内显示“活动待建设”，没有进入未开放工作台的按钮。新增内容未因此获得完整教学能力。

## 与设计稿的接入关系

| 设计要求 | 正式实现 |
|---|---|
| 全景 → 章节／单元 → 目标 | 章节模块、目录、搜索、等价目标列表共用同一选择 |
| 局部关系 | HTML 可聚焦节点、SVG 有向先修／应用线、无方向概念关联线；按声明关系绘制，来源逐条可展开 |
| 位置恢复 | URL 保存课程、章节、目标、视图、关系开关、状态筛选与搜索；刷新／前进／后退恢复 |
| 局部更新 | 当前目标位置固定；切换关系不随机重排；缩放、局部二维滚动和重新定位可操作 |
| 唯一目标统计 | 所有分布按稳定目标 ID 去重；搜索、过滤和关系开关不改变整课分母 |
| 目标与证据 | 必要表现逐条显示满足／不足／待审阅及真实原因；显示核验版本和提交快照的帮助范围 |
| 历史与来源 | 当前有效本机核验参与状态；其他版本或账号恢复记录保留历史并明确不自动承接 |
| 下一步 | 实际工作台入口与能力限制明确；继续位置来自本人空间；无活动时可另建个人课程记录尝试 |
| 手机交互 | 目录可收起，主要操作可达；图谱滚动限制在局部；选择目标后可定位同页详情 |
| 模拟隔离 | 正式页面没有设计稿的模拟核验按钮，模拟记录不会写入学习档案 |

正式默认课程视图选择 HTML＋SVG，是为了让目标卡片直接支持语义按钮、文字换行、键盘导航与关系来源。个人课程的既有 Cytoscape 图谱继续使用相同四类状态与唯一计数契约；这次没有宣称通用课程作者接口或所有个人课程结构已经完成。

## 课程契约修正

- CS03 `0.2.0` 范围使用新的课程版本 UUID，与目录元数据一致；旧记录保持原版本，不改写历史。
- 固定检查器与 Agent 请求契约共用当前 CS03 版本常量，拒绝旧范围请求。生成 OpenAPI 与 TypeScript 同步更新。
- 同一稳定目标可被不同章节／单元引用；同一个位置内重复列出仍拒绝，遗漏目标与目录结构冲突仍拒绝。
- 前后端拒绝严格先修循环；概念关联允许合理循环，关系不传播掌握状态。

## 2026-10-08 第二轮：地图布局重做

用户指出正式预览与设计稿仍有明显差距。本轮重做默认课程的地图表现，不将此前行为测试通过视为视觉验收通过。

- 将目录、地图与证据栏收进一个连续工作区，压缩标题与辅助说明，范围说明按需展开。
- 课程全景以章节区域和可点击单元节点表达归属；跨章连接仅来自课程包实际声明关系，不为装饰编造路径。
- 打开章节先显示本章全部目标，不替学生自动选择第一个目标。选中后高亮圆形知识节点及其文字标签；其他节点保留在原位置，跨章节点明确标记引用。
- 同列关系从圆形节点上下边缘连接，跨列关系采用弧线绕过文字。严格先修有箭头，概念关联无方向，应用使用虚线。逐条来源可展开查看。
- 支持拖动空白画布、方向键平移、缩放、适应画布和定位当前目标。窄屏局部网络改为纵向，CS05 的两个声明目标不再将第二个挤出屏幕；手机目录仍可收起。
- CS05 没有声明完整章节，因此保持小型真实网络；本轮没有增造课程内容或模拟学习证据，也没有修改个人课程的 Cytoscape 实现。

新增回归覆盖章节全部目标可达、CS05 小型网络与手机双节点宽度。原有三列布局测试改为验证章节网络与真实证据的行为。截图和最后测试数字以下一段为准。
