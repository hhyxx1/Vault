# 知识图谱交互与视觉设计提案

日期：2026-10-08
状态：已按用户指定方向接入默认课程正式前端；功能覆盖与未完成验收见 [实施记录](FRONTEND_ATLAS_IMPLEMENTATION.md)，不代表完整课程或生产交付通过。
交互设计稿：[知识图谱设计稿](prototypes/knowledge-atlas/index.html)

## 1 设计目标与边界

学生打开图谱，应能回答三个问题：这门课声明了哪些内容，我的哪些目标已有证据、哪些仍待验证，接下来可以做什么。图谱连接课程结构、个人证据与理论实践活动，帮助学生持续学习。

本提案遵守 [PRD](PRD.md) 第 4 节课程范围与动态图谱要求、[学习闭环设计](LEARNING_LOOP_DESIGN.md) 第 6 节、[用户流程](USER_FLOWS.md) UF02 和 [前端品质标准](FRONTEND_DESIGN_STANDARD.md)。默认课程、教师自建课程和个人课程使用相同的图谱语义；课程来源、范围审阅状态与资料权限分别呈现。

设计稿使用数据结构课程的局部设计示例：8 个章节、16 个单元、32 个唯一目标。数量只用于验证信息组织与交互，不能称为完整课程、已审校课程或真实学生记录。页面持续标注“设计演示 · 模拟数据”，模拟核验与重置只影响该演示，不调用生产学习写入接口，不写入真实本地空间或账号档案。当前默认课程完整交付仍为 **0／13**；本提案不改变该状态。

## 2 信息组织：从课程全景进入具体学习

### 2.1 三层浏览

| 层级 | 学生需要看见什么 | 主要动作 |
|---|---|---|
| 课程全景 | 课程来源、声明范围及版本；章节之间的组织；去重目标数量与四类状态分布；未补全或待核对说明 | 选择章节、搜索目标、切换统计范围、继续上次目标 |
| 章节与单元 | 当前章节的单元、可检验目标及必要先修；局部网络保留全课定位 | 展开单元、选择目标、查看关系、回到全景 |
| 目标与证据 | 要求学生能做什么、已有依据与缺口、帮助程度、活动能力、下一步 | 继续尝试、回顾原理、直接核验、查看作品与历史 |

全景首先展示章节，章节展开后显示单元与目标，不在初始屏幕把全部目标和关联线叠在一起。章节不是一个可检验目标；单个子目标通过时，章节更新分布与计数，不整体变成“已掌握”。

目录和图谱共用课程结构与选择状态。搜索命中目标时显示章节／单元路径、状态文字；选择结果后定位所属局部图谱并打开详情。目标在多个单元被引用时，搜索只算一个唯一目标，可列出多个入口。没有结果时保留搜索词，并允许清除条件、回到课程全景。

### 2.2 桌面布局

宽屏采用左目录、中图谱、右证据的连续学习空间。左侧解决“在哪”；中间表达“结构与关联”；右侧解释“依据与下一步”。顶部只保留课程、范围、版本和最重要的状态摘要，避免与图谱竞争注意力。

```text
课程来源与版本    统计范围    当前范围的目标分布    继续上次目标
┌──────────────┬────────────────────────────┬──────────────────┐
│ 搜索         │ 课程 / 当前章节 / 当前单元 │ 选中目标         │
│ 章节目录     │                            │ 必要表现与依据   │
│ 单元与目标   │ 章节全景或单元目标局部图   │ 还缺什么         │
│ 当前选择     │                            │ 可开展的活动     │
│              │ 图例 / 关系显示 / 定位     │ 下一步与历史     │
└──────────────┴────────────────────────────┴──────────────────┘
```

目标卡片使用真实 HTML 文本与按钮，关系通过 SVG 绘制。卡片宽度、内边距和文字行高保持阅读节奏；长中文标题允许换行，不把重要目标名称截成无法辨认的缩写。布局为稳定的分层结构，节点不会持续浮动；切换关系或更新证据不重新随机布局。

默认课程正式实现已使用 SVG 关系与 HTML 语义节点，保留等价目录和真实证据面板。2026-10-08 第二轮将全景改为章节区域，将章节局部改为圆形知识节点网络，并接入平移、缩放与窄屏纵向布局。个人课程仍使用 Cytoscape.js；技术取舍和本轮验收边界见 [图谱实施记录](FRONTEND_ATLAS_IMPLEMENTATION.md)。

### 2.3 手机、平板与横屏

- 手机全景以章节模块列表呈现，展示同样的范围、目标分布与章节入口；不将三栏机械缩成不可读的小图。
- 进入章节后保留局部图谱和等价的目标列表；详情在同页紧接图谱出现，可明确返回当前目标位置。需要二维滚动时限制在图谱区域，页面导航与主要操作保持可达。
- 窄屏搜索与目录可收起，但入口、当前路径与选择状态保持可见。打开和关闭目录后恢复键盘焦点。
- 平板根据可用宽度将详情放到图谱下方，不挤压目标标题。手机横屏同时考虑较低高度，避免固定头部和底部按钮占满内容区。
- 验收覆盖 320 px、常用手机／平板／桌面视口、横屏与 200% 缩放；这些是待执行的设计检查条件，不是已通过记录。

## 3 节点、关系与证据语义

### 3.1 四类证据状态

| 状态 | 对学生的含义 | 详情必须解释 |
|---|---|---|
| 已有独立达标证据 | 在记录条件下满足该目标当前必要标准 | 哪些作品、核验、版本及帮助记录支持判断 |
| 部分满足 | 有可靠依据支持部分条件，或在帮助后完成 | 已满足什么、仍缺什么、帮助影响哪些结论 |
| 需要巩固 | 有效证据显示必要表现不足 | 具体不足及可继续的练习或修改 |
| 未评估 | 尚无足够可靠依据 | 可开始学习或直接核验已有基础 |

“未评估”保持未知，不等于未掌握；进入活动、阅读和聊天不自动变成部分满足。状态通过文字、图标或形状和色彩共同表达，不只用颜色。

活动进行中、待复核、证据冲突、环境未支持、资料无权限和需要再检验使用独立说明，不混入四类能力状态。运行成功、检查通过、独立完成与目标达标分别展示。必要条件未满足时不能靠其他条件高分平均得到达标，也不因时间过去直接判定遗忘。

### 3.2 关系的分层呈现

| 关系 | 默认呈现 | 选择后可查看 |
|---|---|---|
| 归属 | 通过章节、单元容器及路径表达 | 所属范围与同一目标的其他引用位置 |
| 严格先修 | 当前局部图中以有向线呈现 | 必须先具备的具体条件、依据及版本 |
| 建议先修 | 单独开关或目标关系清单，不与严格先修混为一类 | 建议原因、可直接核验或调整路线的方式 |
| 概念关联／应用关联 | 选中目标后按需显现，使用不同线型和文字图例 | 关联含义、适用范围、来源及方向 |
| 证据支持 | 目标详情中按条件列出，必要时进入证据关系视图 | 作品、核验、帮助及其实际覆盖条件 |

严格先修的有向关系需检查无环；概念与应用关系允许合理的环。布局不能生成课程未声明的先修。任一关系都不传播学习结论，后继目标达标不意味着前驱自动达标。只有活动明确需要的前置条件可限制对应活动，未知状态不普遍锁住整课。

### 3.3 目标详情与下一步

详情顺序为：目标名称与路径 → 必要表现 → 当前证据和未决项 → 可开展活动 → 下一步 → 来源与历史。每条必要表现可展开到实际作品和核验；作品、活动、规则与环境版本关联，帮助范围可检查。

主要动作随上下文变化：有未完成尝试则“继续尝试”，需要补充概念时“回顾原理”，已有基础时“直接核验”。动作进入具体目标与活动版本，并恢复原作品与待完成操作；不得用一个泛化的“开始学习”按钮掩盖未建设活动。Agent 建议说明所依据的表现，学生可调整路线。

## 4 范围、版本与去重

全课核心、扩展选修、当前个人计划分别有明确范围。页面显示“当前范围 N 个目标，其中 M 个已有独立达标证据”，可附目标达标占比 `M/N`。比例是证据统计，不是精确掌握概率，也不预测考试分数或剩余学习时间。

分母只包括当前范围版本中的唯一可检验目标。章节、单元、题目和重复引用不加入分母。目标可在多个单元出现，引用共享同一稳定 ID 与证据；父节点聚合其包含的唯一目标，课程汇总再次去重。两个章节各自含同一目标时，章节数值不能简单相加得到整课总数。

搜索、状态筛选、展开、隐藏连线和局部图切换只改变展示，明示“正在显示的子集”，不改范围分母。范围没有目标时显示“暂无可统计范围”；仅有个人草案或局部内容时显示“已定义范围／仍待补全”，即使局部全部达标也不能称整门课已掌握。

课程或标准更新保存新版本与变化说明；历史证据仍关联原版本。只有经确认等价的目标与必要标准才能承接证据，新增或不等价条件保持待核验。用户应能区分“新增了目标”与“既有目标表现变化”，避免把分母变化误解为能力下降。

### 目标多处引用的实现修正

[课程包规范](COURSE_CONTENT_SPEC.md) 和 [学习闭环设计](LEARNING_LOOP_DESIGN.md) 的多处引用要求已落实到前后端课程包验证。同一稳定目标可出现在不同章节／单元，实体、证据与全课计数仍唯一；同一位置重复列出、未知引用、遗漏目标和非法目录嵌套继续拒绝。章节统计按各自引用去重，不直接累加成全课分母。

## 5 状态更新与持续学习

真实更新顺序为：学生完成尝试 → 获得真实结果 → 按当前必要条件核验 → 记录实际覆盖的目标与帮助 → 更新对应目标 → 去重重算父层分布 → 给出可继续的下一步。一次核验覆盖多个目标时，逐目标记录具体条件；标签相关不算证据覆盖。

更新保留当前选择、展开层级、缩放和位置，并用可关闭的文字说明触发原因。动画只帮助定位刚发生的局部变化，支持打断和减少动态效果。结果来自旧作品时保留在原尝试，不覆盖新版作品的判断；证据删除、同步补入、争议处理和版本变化同样解释原因。

设计稿中的“模拟核验”只改变栈推演示例目标，再重新计算包含它的章节与课程汇总；不会点亮相邻节点或其先修。反馈必须带“模拟”文字，并说明改变了哪个示例条件、还有什么未验证。它演示界面更新，不证明真实学习闭环已经可用。

## 6 来源、权限与异常状态

课程结构与个人证据分开保存、授权。默认课程展示平台内容来源与审阅状态；教师课程展示独立发布版本和范围；个人课程展示本人确认的草案范围及未核对项。课程结构可访问不意味着个人证据可访问；教师只在授权范围内取得学生状态与作品。

本地记录、外部导入、学生自评与平台可信核验使用明确来源，不因同步、换设备或导入升级可信度。访客到账号的承接遵循已有空间归属规则；切换账号不复用他人的状态。图谱、列表、详情、搜索结果、接口和缓存使用一致权限；资料私有来源不得通过节点说明或证据引用泄露。

| 场景 | 界面行为 |
|---|---|
| 课程范围未定义 | 显示缺口与建立／确认范围入口，不伪造章节或百分比 |
| 有范围但没有证据 | 目标保持未评估，提供开始尝试或直接核验入口 |
| 局部示例／模拟数据 | 持续可见的演示标识，与真实档案隔离 |
| 加载失败 | 保留已选课程与视图，说明失败范围并提供重试；缓存有版本与过期说明 |
| 活动未支持 | 目标继续保留在范围内；列出缺少的能力与实际可用的外部提交／人工复核路径；没有路径时不显示可执行按钮 |
| 工具失败／待复核 | 保留作品与恢复入口，不计为学生做错或自动通过 |
| 无访问权限／授权撤销 | 停止获取受限内容，说明权限变化；不暴露私有资料名称、切片或旧缓存 |
| 证据或版本冲突 | 显示冲突原因及受影响的必要条件，提供复核入口，不由界面任选通过 |
| 筛选后为空 | 解释当前筛选，提供清除；整课统计范围保持不变 |

## 7 视觉语言

视觉主题是清晰的课程结构与可追溯学习路径。章节提供稳定空间位置，目标卡片表达可以检验的行动，关系线只承担结构含义；避免装饰星空、持续粒子运动和无法阅读的关系毛团。

| 用途 | 令牌 | 使用原则 |
|---|---|---|
| 页面背景 | 冷白 `#f5f7fb` | 与白色内容面板形成轻微层次 |
| 主文字 | 墨蓝 `#192941` | 课程、目标、正文主信息 |
| 选择与主操作 | 焦点蓝 `#315fe7` | 当前目标、键盘焦点和主要动作 |
| 达标 | 青 `#16826b` | 只表达已有独立达标证据 |
| 部分满足 | 琥珀 `#a56a1a` | 表达部分条件与帮助依赖 |
| 需要巩固 | 紫 `#8852a7` | 与工具错误、危险操作区分 |
| 未评估 | 灰 `#7a8597` | 保留未知，不表达禁用或不能学习 |

采用现代中文无衬线字体，建议字体栈为 `"Microsoft YaHei UI", "PingFang SC", "Noto Sans CJK SC", sans-serif`。标题、节点正文、证据说明与辅助信息具有稳定字号和字重，不通过过多字体或大写小标签制造层次。正文左对齐，主要内容保留充分留白；目标卡片尺寸随内容适度变化，章节容器与目标卡片避免使用完全相同的视觉样式。

颜色令牌是设计起点，实际组合仍需测量对比度。状态色配文字／符号，边与选中状态不能仅依赖颜色。悬浮提示只能补充信息，关系含义和来源也可通过点击与键盘获得。

## 8 设计验收与后续实现

以下为正式产品的验收要求，不构成整模块通过报告。设计稿先供用户检查信息组织和学习体验，再依据确认方向接入正式产品。2026-10-08 的独立设计稿已完成 5 项模型与 12 项浏览器检查；实际覆盖、截图和限制见 [设计稿验证记录](prototypes/knowledge-atlas/README.md#实际验证结果)，不能将其替代真实课程／证据／权限验收。

| 检查面 | 需要核对的结果 |
|---|---|
| 结构与导航 | 全景进入章节、单元、目标及返回路径明确；目录、搜索和图谱选择一致 |
| 语义与统计 | 四类状态解释准确；父节点按唯一目标聚合；多处引用、筛选、折叠不改变分母 |
| 动态闭环 | 模拟核验只改变被覆盖目标和父层计数；保持视图；明确模拟、不写真实档案 |
| 学习动作 | 详情解释依据、缺口、帮助及下一步；未支持活动不伪装可执行 |
| 来源与权限 | 范围／规则版本、内容状态、证据来源清楚；无权资料不通过关系详情泄露 |
| 可访问性 | 键盘可操作搜索、目录、目标和详情；焦点可见；等价列表保留关系与动作；减少动态效果可用 |
| 响应式 | 320 px、横屏和 200% 缩放不遮挡主要动作；图谱二维滚动不使页面溢出 |
| 八维品质 | 分别检查排版、留白、视觉层级、色彩、动效、微交互、响应式、原创性，并记录发现与修正 |

正式实现清单：

1. 用户评审课程全景、局部网络、证据面板和手机路径，记录接受与调整项。
2. 统一课程领域模型、稳定目标 ID、目录引用、关系类型与范围版本；修复多处引用冲突，补充去重与循环校验。
3. 将图谱、目录、搜索、关系列表和详情接入同一真实投影；迁移当前样例硬编码，保留内容未建设状态。
4. 接入真实证据、逐条件判断、帮助、来源、权限、版本变化与恢复位置，不把设计稿模拟核验复制为生产判断。
5. 接通已有活动与真实作品；未建设的执行／核验能力按限制展示，逐活动完成理论实践与恢复流程。
6. 执行范围、状态、权限、动态更新、浏览器闭环、无障碍与响应式测试，记录实际结果和未覆盖项。
7. 完成八维视觉自检与独立复核，修正可见问题；课程内容完整验收仍按 CS01–CS13 的原有计划分别推进。
