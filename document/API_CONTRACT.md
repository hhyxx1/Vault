# API 与异步事件契约

版本：v0.4

状态：逻辑语义基线，具体路径、认证、REST／fetch SSE／WS及序列化已选，见 [物理与API契约](TECHNICAL_DATA_CONTRACT.md)。第 10 节单列已有账号／同步开发切片；个人课程已有私有草稿和尝试的同步切片，API-18 的完整课程、活动、图谱与辅导契约仍未实现。完整 OpenAPI 由实际服务生成并验证。服务端在任何操作中解析账号及数据归属，客户端提供的 owner 不具授权效力。

## 1 通用契约

| 项 | 契约 |
|---|---|
| 请求上下文 | 会话凭据；空间／课程／活动标识；明确的对象版本；稳定 `request_id`／幂等键。来宾操作附本地空间签发的临时、限权运行声明，不向远端开放永久身份 |
| 成功 | 返回 `request_id`、对象／事件标识、有效版本和确定状态；异步操作返回 `job_id` 和查询／取消权 |
| 错误 | 稳定机器码、可读说明、是否可重试、冲突版本／解决动作；不把网络／权限／工具错误改写成内容不正确 |
| 并发 | `expected_version` 或等价前置条件；版本不同则返回冲突及可比差异，不静默覆盖 |
| 事件 | 单一任务 `job_id`；事件带单调 `sequence`、`type`、`occurred_at` 和 `attempt_id`。断线可依据游标续读，事件终态唯一 |
| 幂等 | 创建／提交、同步写入和核验应用同一稳定幂等键不得重复执行或重复推进；相同键但内容不同返回冲突 |
| 权限 | 请求解析后的账号类型、对象空间、共享授权、发布实例、每资料课程绑定可见性、可信使用目的、答案规则、配额每次重新验证；撤销或换号后旧 token／工作流不保留旧访问 |
| 内容版本 | 课程、目标、活动、测试、Skill、答案策略、资料／解析／切片均携带不可变 `*_version_id`；引用版本与提交结果一并返回。可变资料授权另带单调 `policy_revision` |

统一错误类型：`UNAUTHENTICATED`、`FORBIDDEN`、`NOT_FOUND_OR_NOT_VISIBLE`、`VERSION_CONFLICT`、`VALIDATION_FAILED`、`QUOTA_EXCEEDED`、`ENVIRONMENT_UNAVAILABLE`、`EXECUTION_FAILED`、`VERIFICATION_PENDING`、`SYNC_PARTIAL`、`RATE_LIMITED`、`INTERNAL_ERROR`。对访客不得返回泄露其他账号对象是否存在的差异细节。

## 2 逻辑操作目录

实际资源路径由实现决定，以下标识供 FR／测试映射，命令为语义操作名。

| API ID | 语义操作 | 主要输入与返回 |
|---|---|---|
| API-01 | 认证上下文 | 认证／刷新／退出；返回账号类型、命名空间标识及认证状态，不接受客户端角色赋值 |
| API-02 | 课程目录／蓝图 | 任意合法课程 ID、课程／蓝图版本；按受众返回来源、范围、节点、关系及审校／发布状态。平台默认、已授权教师发布课与本人私有个人草案分区呈现；未发布版本不可进入正常支持目录，个人草案与教师自建课程不冒充平台默认课程 |
| API-03 | 创建／确认／修订目标 | 空间、本地 ID、目标草案／期望版本；返回学生确认状态、映射目标和当前路线版本 |
| API-04 | 创建／恢复活动 | 目标、活动与课程版本、作品引用；返回活动状态、待学生动作、作品／恢复版本 |
| API-05 | 请求教学协作 | 活动、学生请求、允许上下文、所需动作；返回 `run_id` 和步骤／学生待办事件。输出为建议 |
| API-06 | 保存产物版本 | 活动／任务、父版本、内容引用、操作者／本地来源；返回持久化版本或冲突 |
| API-07 | 创建／取消执行任务 | 运行时 ID、源码或配置版本、允许输入、额度；返回 job 及真实 stdout／stderr 引用、退出／资源状态 |
| API-08 | 提交核验 | 作品／推演版本、目标、活动／标准／课程版本、已有工具事实；返回各条件结果、适用证据目标、待复核原因 |
| API-09 | 课程图谱与状态摘要 | 账号／访客空间和蓝图版本、统计范围；返回去重目标、父节点聚合、来源和状态投影 |
| API-10 | 关联本地空间／同步批次 | 认证账号、显式当前未绑定空间、对象批次、游标；当前可承接本人私人课程草稿和不可改写的自述尝试；完整范围／目标版本、证据引用、附件和产品删除仍待实现。逐项返回成功、冲突或待上传状态，不将个人草案转为公开课程 |
| API-11 | 个人资料与 Skill 生命周期 | 上传／创建／试用／版本／校核／分享动作、范围和权限；禁止包内容改变平台角色或工具许可。课程教学资料统一采用 API-15 授权契约，不存在宽松的替代上传／读取入口 |
| API-12 | 教师关联、授权及发布 | 关系、范围／目的、任务实例、答案策略和版本；返回被授权视图与当前发布规则 |
| API-13 | 导出／删除／保留请求 | 当前空间所有权确认、对象集和策略版本；逐对象返回排队、完成或失败；审计规则单列 |
| API-14 | 教师创建／版本／能力检查／发布课程 | 课程草案、独立范围与深度、资料绑定、目标／活动、预期版本及发布受众；返回稳定课程 ID、`teacher_custom` 来源、草案／发布版本、能力检查结果及尚需教师确认项 |
| API-15 | 教学资料上传／解析／可见性／撤回 | 原件引用及 hash、课程绑定、预期版本／授权修订、学生可见开关及受众；返回原件／解析版本、异步任务、页码定位状态、绑定授权修订和已生效撤回状态 |
| API-16 | 教师备课／学生 RAG 检索 | 问题、课程／发布实例及允许的资料筛选；服务端确定身份与可信目的，返回按当前权限与答案规则筛选的来源版本／切片定位或无可用资料，不允许客户端指定所有者或扩大检索范围 |
| API-17 | 模型配置／可用目录／职责路由 | 本人或有权使用的模型 profile、协议、能力、职责默认及单次选择；公开目录不含密钥／私有 URL，调用返回实际使用的配置版本和费用归属。当前只实现可信部署配置的目录与单次选择；个人配置和密钥管理仍待实现 |
| API-18 | 学生个人课程创建／确认／版本／恢复（完整契约待实现） | 课程名、问题、目标或本人资料至少其一及本地空间／账号上下文；返回私人课程与范围／目标版本、学生确认状态、未补全项、逐活动能力、证据引用和继续位置。当前仅有本地草稿／尝试与 API-10 私有同步切片；不经过教师发布，也不标为整课已审校 |

## 3 工作流事件类型

允许类型需版本化：`run.accepted`、`step.started`、`assistant.delta`、`student.input_required`、`student.input_received`、`tool.requested`、`tool.progress`、`tool.completed`、`evidence.pending`、`evidence.recorded`、`sync.progress`、`resource.parse_progress`、`resource.index_ready`、`resource.access_revoked`、`run.paused`、`run.resumed`、`run.cancelled`、`run.failed`、`run.completed`。重连事件按 `run_id` 和最后已确认序号继续；重复事件以稳定事件 ID 去重。资料任务事件仅对有权查看任务的主体可见；学生不据此得知私有资料名称或存在性。

结束 `run.completed` 仅表示协作任务结束，不代表活动完成或目标达标。工具结果未收到时不得先发成功事件。取消无法收回已完成外部执行，但后续迟到结果绑定原 job、空间和作品版本，不写入当前其他账号／当前作品。

含资料内容的事件在发送和重连回放前必须复核当前权限；撤权后不继续发送旧 `assistant.delta`、来源片段、工具参数或历史受限载荷。已发送内容无法收回，但仍须拒绝后续下载、缓存命中和运行恢复访问。

## 4 同步操作契约

每条同步操作由 `(space_id, object_id, op_id, parent_version, payload_hash)` 唯一标记。接收端由认证上下文确定账号；客户端 owner 只作一致性核验。上传／删除／关系引用先验证所属空间和课程版本，逐条返回对象状态。附件以不可猜测临时上传权上传，完成后提交 hash、长度和关联对象校验。批次可部分成功，重试未完成操作幂等；删除标记和撤权优先于旧设备回传。

访客在线运行通过独立短时令牌限定可执行模板、资源额度、租期和清理规则。取消、过期和提供方失败分别返回原因；默认不授予读取访客云端学习档案的能力。具体时限列为上线前运营决策。

## 5 核验请求与返回样例

```json
{
  "request_id": "stable-client-operation-id",
  "space_id": "owned-or-local-space",
  "course_version_id": "course-version",
  "activity_version_id": "activity-version",
  "objective_id": "CS03-STACK-02",
  "artifact_version_id": "artifact-revision",
  "standard_version_id": "criterion-version",
  "source_attempt_id": "attempt-id",
  "client_claim": "submitted-work"
}
```

服务器解析真实 owner 与角色；`client_claim` 只是用户提交内容，不能指定状态。返回各条必要条件的 `met`／`not_met`／`not_evaluated` 及工具状态、标准与实际作品引用、适用目标 IDs 和原因。业务服务仅追加核验事件；课程状态投影按版本规则计算。样例标识演示契约，不是可用线上 API。

## 7 自建课程、资料与 RAG 细化契约

### API-14：独立课程与发布

创建仅教师身份可用；服务端生成非枚举 `course_id` 和所有者，客户端不能创建 `platform_default` 来源。输入可包含人工草案或 AI 草案引用；没有上传资料也可创建空白课程。AI 输出不会直接发布。能力检查逐活动返回 `available`／`requires_external_evidence`／`unavailable`、所需工具、实际核验方式及原因；检查不代替教师审阅。发布固定课程范围、深度、目标、活动、标准和受众，并要求明确确认尚需人工／外部实践的边界。未定义可完成的实践／提交／核验路径的活动不能开放为可执行／可核验；其待适配目标保留在图谱及分母中并明示限制，教师可以发布已经具备路径的活动，不能用文字生成声称缺失能力已支持。更新产生新课程版本，旧学习实例保留原范围；迁移须有显式目标映射。

教师自建状态为 `draft → structured_validated → teacher_reviewed → scope_published → superseded`；平台默认课程保留 `draft → structured_validated → content_reviewed → course_accepted → published`。平台验收与官方目录收录另有字段，教师范围发布不自动变成平台已验收。相关用户流程见 UF09，页面见 P10；UF07 继续负责教师任务发布。

### API-15：资料版本与授权绑定

上传完成须核对 hash、长度、支持类型与来源，生成不可变 `resource_version_id`；解析和索引异步状态为 `pending`／`running`／`ready`／`failed`，返回可恢复失败说明。原件可下载不等于解析已完成。新资料及每个新课程绑定默认 `teacher_private`；授权写入至少携带 `binding_id`、课程／发布范围、`student_visible`、受众及 `expected_policy_revision`。修改先校验教师所有权或被授予的编辑权，客户端学生不可通过同一字段设置可见性。

第一阶段资料类型至少为 `.ppt`／`.pptx`、PDF、DOCX、TXT 与 Markdown；旧 `.ppt` 返回受控转换状态与转换版本。解析结果返回页／幻灯片定位、备注／隐藏页／嵌入附件清单及扫描／图表遗漏警告。发布预览须让教师确认学生实际可见内容；若排除原件部分内容，返回独立 `student_copy_version_id`，学生切片和下载绑定该副本，禁止下载完整原件绕过过滤。

绑定同一原件到不同课程不继承学生可见开关；资料升级不把原版本的分享自动扩大到新版本。关闭学生可见、撤回、删除或撤销受众授权时，成功返回前须确认权威 ACL 已生效；响应明确 `access_revoked` 与 `cleanup_pending`／`cleanup_complete`，异步索引清理不能延迟访问拒绝。删除后的原件保留和清理按留存规则执行，任何留存副本仍不可对已撤权主体提供。

### API-16：可信目的与检索发出

教师备课入口与学生问答入口由服务端验证身份、课程受众及业务动作；客户端传 `purpose` 只作请求意图，不授予权限。学生候选集合必须同时满足当前课程访问、有效发布绑定、显式学生可见、受众授权、解析就绪和任务答案策略，教师私有资料不得进入学生检索或 Agent 上下文。检索范围前滤、命中加载、模型上下文组装、结果缓存命中、答案／流式片段发出和事件回放各阶段均复核最新 ACL；无法确认则拒绝受限内容。RAG 可返回“无可用课程资料”，通用辅导若继续须清楚标注未依据课程资料，不能伪造引用。

返回来源仅包含允许的资料显示名、版本、页／幻灯片／段落定位、切片引用与授权修订；下载原件、切片直读和引用展开使用相同权限。允许的资料仍不得绕过老师控制的完整答案规则。缓存、摘要、共享记忆和 Agent 转交不构成例外；日志只保留最少来源 ID／策略结果，不默认记载私有切片正文。

教师私有来源生成的派生产物以教师草案返回；显式审阅发布须记录来源谱系、教师确认、产物版本、受众和答案策略，授权只及该产物。未经此动作不得出现在学生响应或学生可见课程内容中。上述操作映射 FR44–FR46，验收涵盖跨课程复用、解析失败、可见性关闭、撤权发生在生成／流式期间、缓存复用和并发版本冲突。完整边界见 [资料与 RAG 设计](RAG_AND_RESOURCE_DESIGN.md)。

受控答案资料／切片／派生产物必须携带不可由客户端解除的原发布实例／策略关联；API-16 的无任务问答、另一任务、API-15／13 的预览／下载／导出等入口均校验这一关联。限制只作用于该受控来源，不扩大到无关联自学内容。教师若选择公开含答案资料，发布检查须提示与受限任务冲突并要求调整。

经教师明确审阅独立发布的派生产物按自身发布授权提供，私有原件不要求授予学生；未独立发布的草案／摘要／缓存仍继承原来源限制。撤回原资料返回相关独立发布物及其状态，教师可同时撤回；未选择撤回的独立版本维持自身授权，不自动失效。选择同时撤回时对应权威授权须在成功响应前生效。

## 8 学生个人课程契约（API-18，规划中，尚未实现）

API-18 对应 [FR48](PRD.md) 和 [UF10](USER_FLOWS.md)，为学生从 13 门之外的计算机专业课程名称、当前问题、个人目标或本人资料启动学习。它不要求教师先建课，也不等同 API-14 的教师审阅和受众发布。当前 `/sync` 已可承接有界的 `personal_course` 与不可改写的 `personal_attempt` 客户端自述记录；这仅是私人传输切片，`/api/v1/courses` 尚未提供完整个人课程领域接口、AI 建课或受控活动能力。以下仍是完整逻辑操作与验收边界。

1. **创建与归属**：输入至少含课程名、问题、目标或本人资料引用之一；只给课程名时本地界面进入可编辑、待确认的探索状态，不要求教材或模型，也不伪造目标或活动。生成稳定的个人课程 ID、来源 `student_personal`、草案版本和当前空间归属。访客创建、编辑和恢复仅在其本地空间持久化；临时在线帮助使用限权 guest lease，不创建服务器上的永久访客课程。本人登录后由服务端会话确定账号所有者，API-10 仅承接当前未绑定空间；教师账号作为学习者也可保有独立私人课程，但同步不能将其发布为教师课程。客户端提交的 owner、来源类型或课程名不能授予他人空间、教师资料或发布权限。
2. **草案与确认**：AI 建议返回来源、待核对项、建议范围、目标／关系／活动及版本，均标为草案；学生可编辑、删除或拒绝，明确确认后才成为本人当前学习范围。无可用模型时仍支持手动定义和确认目标，不返回虚构的生成结果。保存与修订携带预期版本和稳定幂等键；冲突保留双方及解决入口。
3. **读取与范围**：API-02 在访客本地或本人账号私有列表呈现个人课程，API-09 返回其独立图谱、已定义目标的去重统计、范围缺口和当前继续位置。响应须分别给出 `personal_draft`／已确认个人范围、未补全／待核对项和逐活动执行／核验能力；不能把个人范围的 M/N 或生成章节当成整门学科掌握度、平台内容审校或官方课程验收。默认 13 门目录与教师发布目录的来源和状态继续独立。
4. **活动、证据与版本**：可开放的活动必须有学生实际尝试与作品／过程，以及真实工具结果或明确标为人工／自评待复核的路径；缺运行环境或可靠核验时返回待适配／待核验，不伪报完成。作品、帮助、结果和继续位置分别引用个人课程、范围、目标、活动及标准的有效版本；范围更新生成新版本，旧证据留在原版本。转向经审校的默认／教师课程须由本人明确选择目标映射和待复核项，不能静默改写历史或自动提升证据可信度。
5. **资料与权限**：个人课程及本人资料默认仅当前访客空间或学生账号可见。教师关联和读取仍需学生单独授权；另建个人课程、复制课程名、无任务问答和资料下载均不得绕过教师发布实例的答案规则或教师资料 ACL。读取、检索、模型上下文、流式输出及恢复均复核当前所有权与来源限制；无法确认权限时不提供受限内容。

完整 API-18 尚未有独立实现端点或生成 OpenAPI；现有同步对象以实际 `/sync` OpenAPI 为准。交付时须以访客刷新恢复、账号承接／切换、仅课程名起步、无模型手动路径、编辑确认、版本证据、范围统计和越权拒绝分别验证，不能仅用页面入口、同步成功或模型生成目录判定 API-18 完成。

## 9 实现格式与访客协议

采用/api/v1、UUID、UTC时间、bigint十进制字符串，If-Match与Idempotency-Key分别控制版本和重复动作。账号Cookie＋CSRF，长任务fetch SSE显式Last-Event-ID；终端使用受限WS票据。长期流每批／回放复查session撤销／期限与来源策略。

访客Agent／RAG／执行走guest lease接口，不借用永久账号空间；idle30min／absolute2h为清理测试初值，重启或到期由本地内容重建。访客不能读取需登录的教师受众资料。claim先写本地journal再提交固定claim_id，响应丢失仅本人查询／幂等重试恢复归属。详细路径和约束以TECHNICAL_DATA_CONTRACT为准；这些规则仍待集成测试。

## 10 当前实际账号／同步契约（2026 年 10 月 5 日）

开发切片已提供 `/api/v1/auth/nonce`、register、verify-email、login、session、csrf、logout、password-reset，以及 `/sync/claims`、本人 `/sync/spaces`、batches／changes／conflicts。旧设计路径统一至 [实际端点表](ACCOUNT_SYNC_IMPLEMENTATION.md)；生成 OpenAPI 和 TypeScript 为当前字段权威。

真实 session 决定账号；expected_account_id 仅拒绝过期请求，不能自授所有权。固定 claim／batch／op 及规范正文 hash 支撑丢失响应恢复和幂等；版本冲突保留双方；附件明确不支持；导入核验不会变成平台证据。同步已接受本人空间的 `personal_course`／`personal_attempt` 自述对象，不能因此推出 API-18 的完整个人课程能力已开放；其他设计端点、长期授权流、教师课程及 RAG 仍未开放。
