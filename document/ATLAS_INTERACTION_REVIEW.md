# 图谱交互复核 · 2026-10-09

本轮保留原稿的白底三栏构图，让点击后的状态变化更连贯。

| 动作 | 当前反馈 |
| --- | --- |
| 切换目标 | 保留节点按位置过渡，260 ms；选中节点置于上层 |
| 更新详情 | 220 ms 淡入及 6 px 轻移；后续选择取消前一次详情动画 |
| 更新关系 | 关系线短暂淡入，不做持续流动、闪烁 |
| 悬停、按下 | 边框、背景和阴影反馈，节点轻微抬起与按压 |
| 打开目录或关系详情 | 内容短暂淡入；关系详情提供关联目标跳转 |
| 手机选择节点 | 平滑定位并聚焦详情；“回到局部图谱”回到选中节点 |
| 只有一至两组节点 | 居中布局，避免空列挤偏整个图谱 |
| 系统要求减少动效 | 关闭图谱 CSS 动画及过渡、详情动画与平滑滚动，保持功能可用 |

动效不改变目标、核验结果与掌握状态；内容未建成的目标继续说明实际边界。原设计稿仍保留在 5176，当前实现运行在 5178。

## 验证

新增测试先确认关联目标跳转、位置过渡、稀疏布局及手机返回入口的原实现缺口，再实现并回归。图谱交互、设计对照、动效及返回操作共 32/32 项通过；类型检查与生产构建通过。

实际 Chrome 检查确认正常选择时详情动画运行 220 ms；390 px 手机完成节点选择、详情定位及键盘焦点切换。截图仅记录稳定视觉，不代表对动画观感的自动验收。
