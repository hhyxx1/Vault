## 第一阶段交付与推进顺序

第一阶段要求 CS01–CS13 **全部课程内容完整、均按课程分别验收**，并支持学生从预设 13 门之外的计算机专业课程名、问题或目标建立私人课程并继续学习。13 门是平台维护的默认课程基线，不限制学生的自主学习入口；私人草案须标明未审校范围，也不能抵扣默认课程验收。开发时先打通相邻单元只代表工程切片，不能缩减课程范围或把单元样例写成整课完成。逐步安排和出口标准见 [开发计划](DEVELOPMENT_PLAN.md)。

推进顺序：按 PRD v1.5 与已选技术建立工程／CI，并行走查关键流程和原创高保真设计 → 首批物理迁移、生成接口与真实闭环纵切 → 并行编制 13 门全量内容、实现 FR48 学生个人课程路径并补齐平台 → 全量课程／功能／视觉／运行验收 → 部署演练与发布。本人自测选课不决定 13 门范围。

## 技术文档现状

前后端、账号／存储／同步、编排／模型、解析／检索、执行和部署已选定，六项ADR接受为开发设计。字段类型、关键约束、端点／事件／错误和guest／claim事务已细化。首个工程建立了依赖锁与 12 张物理表，后续 `0002`–`0005` 增加邮箱认证、同步、账号 Agent 账本及个人课程自述记录的受限同步类型；FastAPI 生成 OpenAPI／TypeScript 并用独立 PG 与浏览器切片测试。真实邮件、教师授权、RAG、隔离执行、Linux 镜像与发布恢复仍待实施，不能由基础工程推导全部通过。

下一步先使课程、目标、活动与证据脱离 CS03 编号约束，为个人课程建立可确认的版本化范围、真实活动和受限多 Agent 辅导；同时推进隔离执行、教师受控资料与各类实验。13 门默认课程内容和高保真页面并行建设；本人选课、价格、公开容量和保留期限按对应阶段关闭。
